慧浪智算 ComfyUI 管理平台识别汇总

1. 项目识别结论

- 项目名称：慧浪智算·FlowPilot
- 项目定位：面向 GPU 服务器的轻量化 ComfyUI 一体化部署与管理平台。
- 当前版本：0.0.7.1
- 当前阶段：真实 Docker 生命周期管理、GPU 分配、模型中心、模型市场、下载/导入任务、一键镜像安装脚本、DGX Spark 实机验证均已形成闭环。
- 核心目标：一次安装、Web 管理、Docker 部署、模型共享、数据持久化。

2. 顶层文件与目录

- README.md：项目总说明、当前版本、部署方式、目录说明。
- CHANGELOG.md：版本变更索引，当前最新为 0.0.7.1。
- VERSION：当前唯一版本号，内容为 0.0.7.1。
- PROJECT_RULES.md：项目协作与版本管理规则。
- docs/mvp/FlowPilot_MVP_PRD.md：MVP 产品需求文档。
- context/conversations/：历史对话摘要、需求决策和上下文。
- context/changes/：分版本详细变更记录。
- code/backend/：Go 后端服务与 Docker API 封装。
- code/frontend/：React/Vite 前端管理台。
- code/deploy/：一体化 Dockerfile 与部署配置。
- code/scripts/：Demo、打包、安装、卸载、远程部署脚本。

3. 技术栈识别

前端：
- 位置：code/frontend/
- 技术栈：React 19、TypeScript 5.9、Vite 7、TailwindCSS、Radix UI、lucide-react、recharts、sonner、zod、react-hook-form。
- 入口文件：code/frontend/src/main.tsx、code/frontend/src/App.tsx。
- 主要页面：Dashboard、Instances、Models、Tasks、System。
- 数据模式：前端已移除演示数据，业务数据全部来自真实后端接口；后端不可用时显示空态和离线提示。

后端：
- 位置：code/backend/
- 技术栈：Go 1.25，主要使用标准库 HTTP 服务。
- 模块名：github.com/ghoul02015/flowpilot。
- 启动入口：code/backend/cmd/flowpilotd/main.go。
- 路由集中：code/backend/internal/server/server.go。
- 后端特点：同时提供前端静态页面和 /api/v1/ API，通过 /var/run/docker.sock 访问 Docker Engine，不引入第三方 Docker SDK。

部署交付：
- Web Demo：code/scripts/demo-docker.sh up。
- 默认访问：http://localhost:18080。
- 一体化镜像：flowpilot-web:0.0.7.1。
- 离线包脚本：code/scripts/package-release.sh。
- 远程部署脚本：code/scripts/deploy-remote.sh。
- 已在 DGX Spark（Ubuntu 24.04 arm64、NVIDIA GB10、Docker 29.2.1）实测。

4. 后端核心能力

- 健康与系统：/health、/system/info。
- 硬件采集：/hardware。
- Docker 信息：/docker/info、/docker/containers。
- 实例管理：/instances、启动/停止/重启/删除、/instances/{name}/comfy/status。
- 模型仓库：/models。
- 模型市场：/models/catalog、/models/online/search、/models/online/files。
- 在线源状态：/sources/status。
- 镜像能力：/images/check、/images/local、/images/catalog、/images/install-script、/images/pull。
- 下载/导入任务：/downloads、/imports。

5. 业务上下文梳理

项目演进主线：Web Demo 与 Docker 交付 → 真实 Docker 生命周期 → 真实硬件采集 → 模型中心 → 下载/导入任务 → 去演示数据 → 任务持久化与 ComfyUI 状态代理 → 模型市场在线源 → 搜索体验优化 → 实例镜像可选与一键安装 → DGX Spark 实机验证。

8. 主要风险与注意事项

1. 当前版本没有认证、用户权限和数据库。
2. 服务会挂载 /var/run/docker.sock，管理端权限较高，不应直接暴露公网。
3. 一键安装脚本会在部分步骤重启 Docker，可能短暂影响同机其他容器。
4. 非交互安装依赖 sudo 条件，生产无人值守建议使用 root、NOPASSWD 或 tmux/screen。
5. 现有安全头较基础，后续生产化建议补充认证、权限、审计和 CSP。

9. 总体判断

该仓库不是简单 Demo，而是已经具备生产交付雏形的 ComfyUI 管理平台。当前功能重点围绕 GPU 服务器上的 ComfyUI 环境管理、实例生命周期、模型仓库、模型市场、下载导入任务、Docker 镜像准备和离线部署。最近版本已经在 DGX Spark 实机完成较完整闭环验证，当前最需要关注的是认证权限、Docker Socket 暴露风险、安装脚本对 Docker 的重启影响，以及无人值守 sudo 条件。
