# 0.0.6.0 — 模型市场：ModelScope 目录，选中即下载

日期：2026-11-08
类型：新功能（次版本位升级，自 0.0.5.1）

## 需求背景

周董要求优化模型中心：添加模型时直接展示主流模型源目录，选中即开始下载；目录数据对接 ModelScope（优先，国内可达）与 HuggingFace（备选，经 hf-mirror.com）。

## 变更清单

### 后端（code/backend）

- 新增 `internal/catalog/catalog.go`：
  - `Entry`：id／名称／类别（决定入库子目录）／类型标签／文件名／描述／大小／ModelScope 仓库与文件路径／主地址／HF 备选地址／HF 是否需授权／可达性。
  - 内置 14 条主流模型：SD1.5、SDXL Base、SDXL Offset LoRA、FLUX.1 dev/schnell、FLUX ae/clip_l/t5xxl_fp8、SD3.5 Large、sd-vae-ft-mse、ControlNet canny、Wan2.1 T2V 1.3B＋VAE、RealESRGAN x4。全部仓库与文件路径经实机 curl 逐条验证存在（注意：AI-ModelScope/4x-UltraSharp 与 Detail-Tweaker-LoRA 在 ModelScope 不存在，未收录）。
  - `Manager`：缓存优先＋内置合并（缓存覆盖同 ID、保留历史条目、补充内置新增）；`Refresh` 并发 4 路查询 ModelScope 文件列表 API 更新 sizeBytes/reachable，原子写缓存（.tmp＋rename，0600），并发刷新拒绝；`msRequestBase` 包级变量供测试替换。
- `server.go`：`New` 第 9 参 `catalogManager`；新路由 `GET /api/v1/models/catalog`、`POST /api/v1/models/catalog/refresh`（25s ctx 超时，409 冲突）。
- `main.go`：缓存路径 `filepath.Join(dataDir, "catalog.json")`（宿主机 `shared/catalog.json`，重装保留）。
- 测试：catalog 包 5 用例（内置完整性／空缓存回落／缓存合并／刷新持久化／并发拒绝）＋接口 2 用例（启用／未启用）。

### 前端（code/frontend）

- `api.ts`：`CatalogEntry`/`ModelCatalog` 类型、`getModelCatalog()`（8s 超时）、`refreshModelCatalog()`。
- `AddModelDialog.tsx` 重写为三标签：模型市场（默认）／URL 下载／本地导入。MarketPanel：打开拉目录、搜索＋类型筛选、条目卡片（名称／类型徽标／大小／描述／不可达标注／已入库标注）、「下载」主按钮（ModelScope）＋「HF 镜像（需授权）」副按钮、「更新目录」。
- `App.tsx`：`marketDownload(entry, useFallback)` 复用既有下载引擎（任务持久化自动生效）；`existingModelPaths`（仓库文件＋进行中任务）用于已入库判断。
- 新增类别 Text Encoders／Diffusion Models，落仓库 `text_encoders/`、`diffusion_models/`。

### 回归脚本（code/frontend/scripts/verify-demo.mjs）

- 新增市场链路断言：目录接口 ≥10 条且全 ModelScope 主地址 → 界面搜索 Offset → 点下载 → 等 49.5MB 真实下载完成入库 → 界面删除并确认 → URL 下载旧流程（补点「URL 下载」标签）。
- 修复 1：主下载按钮与 HF 镜像按钮 aria-label 前缀歧义（strict mode violation），改 `exact: true`。
- 修复 2：删除前增加 `waitForFunction` 守卫——等 dl- 任务行消失、仅剩仓库文件行（界面 3s 轮询滞后于 API，曾误点任务行触发 409 cancel 而非删文件）。

## 验证结果

- Go：`gofmt`＋`go test ./...`＋`go vet ./...` 九包全绿（golang:1.25-alpine 容器）。
- 前端：lint／build 通过。
