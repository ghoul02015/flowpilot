# FlowPilot 0.0.4.1 变更记录

日期：2026-11-08
主题：测试评审＋实机验证补丁（周董指令：做测试评审、找 bug、在实体机器上验证）

## 评审方法

1. 静态评审：逐文件审查后端 download／instance／server／model／docker 包、前端关键交互与安装/卸载脚本。
2. 单元测试：为每项修复补针对性用例。
3. 实机验证（DGX Spark 192.168.0.77）：33 项 API 边界/异常路径测试＋容器内只读挂载实测＋卸载/重装闭环＋34 项 Playwright 远程回归。

## 发现与修复（6＋1 项）

| # | 级别 | 问题 | 修复 |
|---|---|---|---|
| 1 | 真 bug | 实例 `start`/`restart` 不校验 GPU 冲突：A 停止→B 建在同 GPU→启动 B→启动 A，两实例共用一卡 | `checkGPUConflict` 启动前校验，冲突返回 400 |
| 2 | PRD 偏离 | 模型目录读写挂载进实例（PRD 10.1 要求只读），实例内可误删共享模型 | models 挂载加 `:ro`，workflows/outputs 保持可写 |
| 3 | 数据安全 | 下载归档 `os.Rename` 会静默覆盖下载期间手工放入的同名文件 | 归档前复核目标存在，存在则失败并保留原文件 |
| 4 | 体验 | 导入任务文案沿用下载措辞（"下载完成"／"可断点续传"，导入恢复实为重新复制） | 按 kind 区分完成/暂停文案 |
| 5 | 健壮性 | 下载 HTTP 客户端无任何超时，对端挂起时任务永远卡在"正在建立下载连接" | Transport 增加 Dial 30s／TLS 15s／响应头 60s 超时 |
| 6 | 性能 | 模型扫描无缓存，前端 3 秒轮询＝持续全盘遍历 | 扫描结果缓存 2 秒，删除操作主动失效 |
| 7 | 交付质量 | 卸载只删当前版本镜像，历次升级的旧 `flowpilot-web:*` 在机器上累积 | 无遗留 FlowPilot 容器时清理全部历史版本镜像 |

## 实机验证记录

- **边界测试 33/33 通过**：非法输入 15（ftp URL、非法类别/SHA256、白名单外导入、相对路径、目录导入、中文实例名、特权端口、GPU 越界、缺失镜像、404×3、未知 API）；冲突与生命周期 11（重名/端口/GPU 冲突、启动时 GPU 占用拒绝、强制删除语义）；下载导入 7（真实下载完成、终态暂停 409、导入文案、重复目标 409、仓库清理）。
- **只读挂载实测**：容器内 `touch /app/ComfyUI/models/x` 返回 Read-only file system；outputs 可写。
- **卸载/重装闭环**：卸载后容器、安装目录、全部 8 个历史版本镜像清零；`comfyui-h3`、`gpustack`、`qwen3.8` 等业务容器与服务全程无恙；重装后安装脚本幂等可用。
- **远程回归 34/34 通过**（含 ComfyUI 实例在只读模型挂载下正常启动与就绪）。
- Go 八包测试全过（新增 4 个用例）；前端 lint/build 通过。
