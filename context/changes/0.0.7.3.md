# 0.0.7.3 变更记录

- 日期：2026-11-09
- 类型：功能／交互优化／测试／部署
- 需求来源：周董「继续优化 ComfyUI 实例：构建/拉取改为弹窗、镜像分类、新建实例只选 ComfyUI 镜像、构建参数细化并生成脚本、清单展示进度和实时日志、Spark 实体验证」

## 背景与目标

0.0.7.2 已将容器镜像管理、手动构建与在线拉取从新建实例弹窗中拆出，但构建/拉取参数仍直接铺在子菜单页面中，镜像清单也未区分 ComfyUI 镜像与其他机器镜像。用户在新建实例时仍可能看到非 ComfyUI 镜像，环境管理体验不够收敛。

本轮目标：

1. 将手动构建和在线拉取改为两个独立弹窗。
2. 本机镜像列表分为 ComfyUI 镜像与机器其他镜像，新建实例只展示 ComfyUI 镜像。
3. 构建参数细化到 CPU 架构、GPU/PyTorch 配方、ComfyUI 版本、pip 源、ComfyUI-Manager 开关，并生成同参数一键构建脚本。
4. 构建任务在 ComfyUI 镜像清单中展示进度百分比、参数简述和日志入口。
5. 部署到 Spark 实机验证。

## 新增内容

### 1. 构建 / 拉取双弹窗

- 「手动构建 / 拉取」子菜单保留，但页面主区域改为两个操作入口：
  - 一键构建 ComfyUI 镜像
  - 拉取在线容器镜像
- 点击后分别打开参数弹窗，避免主界面长期展示大量构建参数。
- 拉取弹窗提示：非 ComfyUI 镜像会进入「机器其他镜像」，不会作为新建实例候选。

### 2. 镜像分类清单

- 容器镜像管理新增两类列表：
  - ComfyUI 镜像
  - 机器其他镜像
- 分类规则：优先识别 Docker Image Labels 中的 `flowpilot.kind=comfyui`，同时兼容镜像标签名包含 `comfyui` / `comfy-ui` 的历史和第三方镜像。
- 新建实例向导仅展示 ComfyUI 镜像。

### 3. 构建参数细化

构建弹窗新增/强化参数：

- CPU 芯片架构：
  - 宿主机架构
  - `linux/arm64`
  - `linux/amd64`
  - `linux/arm/v7`
- GPU / PyTorch 配方：
  - NVIDIA CUDA 13.0
  - NVIDIA CUDA 12.8
  - NVIDIA CUDA 12.6
  - NVIDIA CUDA 12.1
  - AMD ROCm 6.2
  - CPU
- ComfyUI 版本：
  - 通过 `GET /api/v1/images/comfyui-refs` 在线读取 ComfyUI GitHub tags，网络失败兜底 `master`。
  - 支持手动修正 ref。
- pip 源：清华、阿里云、PyPI。
- ComfyUI-Manager：内置 / 不内置。

### 4. 一键构建脚本

- 新增 `GET /api/v1/images/build-script`。
- 根据构建弹窗参数生成只构建镜像的 shell 脚本。
- 脚本包含参数简述和 Dockerfile，不安装 FlowPilot、不下载模型。
- 支持 `--platform`，为后续集群/跨架构分发做准备。

### 5. 构建进度与日志入口

- 后端构建状态新增：
  - `progress`
  - `summary[]`
- Docker 构建日志会被解析为近似进度：
  - `Step N/M` → 估算百分比
  - 镜像写入/打标签 → 约 95%
  - 完成 → 100%
- ComfyUI 镜像清单中展示：
  - 构建进度条
  - 百分比
  - 参数简述
  - 日志图标
- 点击日志图标可打开实时构建日志弹窗。

### 6. 构建镜像标签

平台构建出的 ComfyUI 镜像写入 Docker Labels：

- `flowpilot.kind=comfyui`
- `flowpilot.build.variant`
- `flowpilot.build.gpu`
- `flowpilot.build.cuda`
- `flowpilot.build.platform`
- `flowpilot.comfyui.ref`
- `flowpilot.comfyui.manager`
- `flowpilot.build.summary`

## 修改内容

- 新建实例向导：从「本机已有镜像」进一步收敛为「本机 ComfyUI 镜像」。
- `GET /api/v1/images/local`：前端使用新增的 Labels 信息做分类和参数简述展示。
- `POST /api/v1/images/build`：请求参数增加 `platform`。
- `GET /api/v1/images/build`：响应增加 `progress` 与 `summary[]`。
- 本地 Demo 脚本新增 `flowpilot/comfyui-regress:<version>` 轻量回归镜像别名，仅用于端到端快速验证生命周期。
- 版本号更新为 `0.0.7.3`。

## 已知风险

- Docker 构建整体进度为近似估算，Docker Engine 未提供统一总进度；平台根据构建日志 `Step N/M` 和关键事件推断百分比。
- 跨架构 `--platform` 构建依赖宿主 Docker/QEMU/BuildKit 支持；若目标架构依赖不可用，构建会失败并在日志中呈现。
- 在线获取 ComfyUI tags 依赖 GitHub 可达；不可达时兜底 `master`，不阻断构建。
- 当前平台仍无认证且挂载 Docker Socket，不应暴露到公网。

## 回滚说明

- 代码回滚：`git revert` 本版本提交。
- 运行回滚：重新安装上一版离线包 `flowpilot-0.0.7.2-arm64.tar.gz`，或将管理容器切回 `flowpilot-web:0.0.7.2`。
- 数据兼容：本轮不引入数据库迁移；Docker 镜像 Labels 为增强信息，旧镜像仍可通过标签名识别。
