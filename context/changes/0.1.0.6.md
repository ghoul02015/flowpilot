# 0.1.0.6 许可提示简化

- 版本：0.1.0.6
- 日期：2026-11-13
- 依据：用户对 0.1.0.5 许可界面的反馈（截图）
- 范围：模型中心卡片、详情「许可与声明」、下载前许可弹窗、许可判定逻辑

## 一、调整原因

0.1.0.5 按《模型中心授权.md》实现了“内部审核：待法务审核”和必选勾选框，实际使用中有两个问题：

1. 平台并不承担法务审核，展示“待法务审核”容易被理解成平台内部有审批流程；
2. 每一步都要求勾选确认，对只做下载的日常操作过重。

本次按用户要求简化为：**下载前提示许可，点击一次确认即可；没有配置许可的模型不提示、不阻断。**

## 二、界面调整

| 位置 | 调整前 | 调整后 |
| --- | --- | --- |
| 卡片状态行 | 许可文本：已确认／待确认 | 许可：已确认／待确认（仅配置了许可的模型显示） |
| 卡片提示 | 使用须遵循模型许可 · 查看许可 | 下载前需确认模型许可 · 查看许可（仅配置了许可的模型显示） |
| 弹窗标题 | 使用 {模型} 前请确认许可条件 | 使用 {模型} 前请阅读许可 |
| 弹窗交互 | 必选勾选，未勾选按钮禁用 | 无勾选，直接点击「确认并继续下载」 |
| 弹窗说明 | 含“不代表本平台授予商业授权或完成法务审核” | “点击确认即表示你已阅读该许可。” |
| 详情「许可与声明」 | 含“内部审核：待法务审核／已通过” | 移除该字段；保留模型、许可名称、日期、快照、确认状态、确认人/时间、许可文件 |
| 详情底部 | “不代表平台完成法务审核” | “确认仅表示你已阅读该许可，不改变模型本身的许可要求。” |

## 三、按需确认逻辑

清单里的 `licenses` 从“每个模型必须有”改为“可以没有”：

- `License.Configured()`：许可名称与模型名都不为空才算配置；
- 未配置许可的模型：`attachLicenses` 跳过挂载，`validateLicense` 跳过校验；
- 预检 `license` 项：未配置时直接 `pass`，说明“该模型未配置额外许可，无需确认”；
- 创建安装：只有“已配置许可且未确认”才返回 422；
- 前端：卡片不显示许可状态与入口，详情页提示“该模型未配置额外许可，下载无需确认”，向导视为已满足。

已配置许可的模型（当前 S1～S5）行为不变：同模型同版本确认一次，版本变化后重新确认。

## 四、代码变更

### 后端

- `internal/bundle/types.go`：新增 `License.Configured()`。
- `internal/bundle/manifest.go`：未配置许可的模型不再导致加载失败，只跳过挂载与快照校验。
- `internal/bundle/manifest_validate.go`：允许清单不配置许可；已配置项仍校验版本、链接、文件与哈希。
- `internal/bundle/preflight.go`：未配置许可时许可项直接通过；文案去掉“法务审核”。
- `internal/bundle/service.go`：仅“已配置且未确认”时拒绝创建安装。

### 前端

- `components/ModelBundles.tsx`：卡片、详情、弹窗按上述调整；弹窗去掉勾选状态；向导把“未配置许可”视为已满足。

### 测试

- `manifest_test.go`：`TestBundleWithoutLicenseRejected` 改为 `TestUnlicensedModelNeedsNoConfirmation`，验证未配置许可可加载、预检通过，已配置许可仍需确认。
- `manifest_test.go`：`reparseManifest` 在序列化前清空挂载的 License，真实模拟源清单未配置许可。
- `store_test.go`：新增 `TestCreateInstallSkipsLicenseForUnlicensedModel`，验证未配置许可可直接安装、已配置未确认仍拒绝。
- `verify-demo.mjs`：许可弹窗断言改为“可直接点击确认、无勾选”。

## 六、与授权文档的差异

《模型中心授权.md》原本要求内部展示“待法务审核”，本次按用户明确要求取消该描述，并将确认简化为一次点击。  
仍然保留的边界：确认只代表已阅读，不改变模型本身的许可要求；许可原文与 NOTICE 仍随包交付。
