# 0.1.0.1 变更记录 — 发行版体验修正

- 日期：2026-11-11
- 类型：修复／优化（发行版体验）
- 需求来源：用户对镜像标签弹窗、任务中心布局、发行版调试文案的反馈
- 发布包：`flowpilot-0.1.0.1-arm64.tar.gz`（MD5 `268d90993db9418e614416d30882498c`，36 MB）

## 问题与根因

1. **镜像标签弹窗风格不一致**：使用浏览器原生 `window.prompt`，与产品 Dialog 风格割裂。
2. **“复制了一个镜像”**：后端执行 Docker 新增标签，界面仍把每个标签渲染成独立镜像行；同一镜像 ID 的多个标签被误认为多份镜像数据。
3. **任务中心空间利用率低**：三栏布局中进度列占据大量空白，终态任务仍保留大进度条，失败/取消任务出现旋转图标。
4. **任务操作不完整**：只有下载任务取消/重试，缺少暂停、继续、记录删除与批量清理；平台备份任务未进入统一列表，筛选后的 total 与分页不准确。
5. **发行版存在研发痕迹**：“真实数据”“真实创建”“阶段 1 版本列车”“本版”等文案；并存在与现状不符的“当前版本无认证机制”提示。
6. **实机残留测试资产**：回归镜像、测试下载/导入/迁移/备份任务记录混入正式环境。

## 新增与修改

### 镜像标签

- 改标签改为产品化“编辑镜像标签”Dialog，支持：
  - **添加别名（默认）**：保留源标签，新标签与源标签指向同一镜像。
  - **重命名**：新增目标标签后移除源标签；源标签被实例引用时拒绝。
- 后端 `POST /api/v1/images/tag` 增加 `mode=alias|rename`，默认 alias 保持兼容。
- 目标标签已存在返回 409；非法目标、源不存在、源标签被引用分别返回明确错误。
- 重命名先做实例引用检查（含已停止容器），再执行标签新增；移除源标签失败时尽力回滚新标签。
- 镜像列表按镜像 ID 分组，同一镜像的多标签集中展示，标注“同一镜像 · N 个标签，不重复占用磁盘”。
- 删除操作区分“删除标签”和删除最后一个标签时的“删除镜像”。
- 镜像中心其余原生 `confirm` 全部替换为产品确认框。

### 任务中心

- 桌面端改为紧凑表格：任务信息自适应，进度固定宽度，时间与操作列固定；移动端使用卡片。
- 活跃任务优先；终态任务不再显示大进度条或错误旋转图标，未知进度显示 `—`。
- 操作矩阵：
  - 下载/导入：暂停、继续、取消、重试、删除记录、详情。
  - 镜像构建/拉取：停止、查看日志、删除记录、详情。
  - 数据迁移/平台备份：详情、终态删除记录。
- 删除仅清理任务记录，不影响模型、镜像、备份文件或实例数据。
- 新增类型/状态/关键词筛选、300ms 搜索防抖、服务端分页（每页 20）、活跃任务优先排序。
- 新增“清理已结束”批量入口，仅清理终态记录；排队、运行、暂停任务永不删除。
- 统一任务列表补齐平台备份任务；筛选后的 total 修正为筛选结果总数。
- 备份聚合从仅 migration 扩展为 migration + backup。
- 详情弹窗增加本地时间、开始/结束时间、失败原因；镜像任务可查看运行日志。

### 文案与资产

- “真实数据/真实后端/真实 Docker/真实创建/真实下载/真实删除”等界面措辞改为中性产品语言。
- 移除关于页“阶段 1 版本列车/UI 打磨（本版）”。
- 修正“当前版本无认证机制”为管理员凭据与 HTTPS 管理网提示。
- 正式发布不预置回归镜像或测试实例；Spark 清理回归镜像 3 个、测试任务记录 39 条。

## API 变化

- `POST /api/v1/images/tag`：新增 `mode`；响应增加 `action/source/target`。
- `DELETE /api/v1/tasks/{id}`：统一删除终态任务记录（dl-/img-/持久化任务）。
- `DELETE /api/v1/tasks?type=`：批量清理当前类型下终态任务记录。
- `GET /api/v1/tasks`：新增 `q` 搜索；correct total；聚合 backup；活跃任务优先。

## 已知边界

- 重命名不会自动改写运行中实例的镜像；被引用时明确拒绝，需先调整实例。
- 任务“重试”仅对下载/导入开放；镜像构建缺少完整配方快照，数据迁移需重新预检，本版不提供通用重试。
- 运行日志当前仅镜像构建/拉取提供；其他任务提供状态与结果摘要。
- 任务记录不自动过期，保留用户主动清理能力。

## 回滚说明

- 部署旧镜像 `flowpilot-web:0.1.0.0` 即可回滚。
- 如需恢复升级前数据库，可使用 Spark `shared/backups/pre-upgrade-20261111-123707.db`。
- 本版无数据库结构变更；任务记录接口与列表语义向后兼容。
