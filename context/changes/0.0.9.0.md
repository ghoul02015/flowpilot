# 0.0.9.0 变更记录

- 日期：2026-11-09
- 类型：修复／结构优化／体验一致性
- 需求来源：周董 2026-11-09 下达的 ComfyUI 实例模块与整体 UI 评审待办清单（P1 3 项、P2 8 项、P3 7 项），经逐项确认后本轮全量落地；镜像任务体系（并发/停止/清理）已在 0.0.8.0 先行完成。

## 背景与目标

0.0.8.0 完成后，周董要求核对评审清单剩余项并全部实施。目标：

1. 消除前端死代码与误导性展示（P1）。
2. 修复交互细节缺陷与校验缺口（P2）。
3. 收敛页面结构、统一品牌色系（P3）。

## 新增内容

- 创建实例时宿主机端口真实监听探测（`net.Listen("tcp", ":"+port)`），18080 管理端口及其他已占用端口创建前拦截（`internal/instance/instance.go`）。
- 前端 `getHealth()` 接口与 `backendVersion` 状态：页脚版本号、系统页诊断包 JSON/文件名/关于面板版本改读后端 `/health`，离线回退编译期常量。
- 新建实例向导无 GPU 数据时显示琥珀色警告条，提示 GPU 检测失败、将按 CPU 创建。

## 修改内容

### P1 修复

- `App.tsx`：新增 `busyIds` 请求级忙碌集合，`instanceAction` 期间传入 `Instances` 禁用按钮（停止/启动/重启锁定、重启图标旋转），替换此前按后端不存在状态判断的死代码。
- `Instances.tsx`：详情弹窗补「工作流挂载」字段；挂载路径类字段（模型仓库挂载/导出资产路径/工作流挂载/容器名称）统一整行展示。
- `Tasks.tsx`：删除前端拼接文本的假日志弹窗，改为「任务详情」面板，展示真实任务字段（dl 定义列表）与失败原因；按钮「日志」更名「详情」。

### P2 修复与增强

- `ImageManager.tsx`：构建弹窗 ComfyUI 版本由「在线下拉＋手动输入」双控件合并为单个 `input + datalist` 组合框。
- `CreateInstanceDialog.tsx`：`suggestName`/`suggestPort` 自动扫描第一个空闲值（comfy-NN、8188 起）。
- `AddModelDialog.tsx`：`onSubmit` 改为 `Promise<boolean>`，创建任务失败时弹窗保持打开、输入保留，新增 `submitting` 提交态。
- `Models.tsx` / `AddModelDialog.tsx` / `api.ts` / `internal/model/model.go`：模型类型补齐 Text Encoders / Diffusion Models / CLIP Vision / Model Patches，筛选与后端类别展示名映射同步。
- 实例详情 GPU 名称过长截断。

### P3 结构与色系

- `Instances.tsx`：tab 从 3 个收 2 个（实例列表／镜像中心）；`ImageManager.tsx` 移除 `mode` prop，合并为单视图「镜像中心」（入口卡片＋ComfyUI 镜像清单＋机器其他镜像＋构建与拉取任务＋磁盘占用）。
- `CreateInstanceDialog.tsx`：向导 3 步收 2 步（镜像与资源／确认部署），纯展示的「模型可见性」并入确认页。
- 页面子菜单选中态由深灰统一为品牌 teal-700（Instances、System）；`common.tsx` StatusBadge 进行中状态由 cyan 统一为 teal 系。
- 实例表格「制图任务」列更名「ComfyUI 队列」，详情弹窗术语同步；操作列删除按钮与其他操作之间加竖向分隔线；开机自启由禁用 checkbox 改为文字徽章。

## 删除内容

- 实例操作禁用判断死代码（按后端不存在状态的判断分支）。

## 已知问题与风险

- 宿主机端口探测在容器内执行时依赖宿主机网络命名空间可见性（部署形态为 host 网络，无影响；桥接网络下探测的是容器命名空间，可能漏报）。
- 页脚版本号在后端离线时回退编译期常量，与后端实际版本可能有偏差（界面已标注离线状态）。
