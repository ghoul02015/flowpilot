# FlowPilot 0.0.5.1 变更记录

日期：2026-11-08
主题：去除全部虚拟演示数据，按真实生产显示＋测试 bug 排查（周董指令：做小版本变动，这次去掉所有的虚拟演示数据，再做一次测试 bug 排查，按照真实生产的页面显示）

## 变更总览

### 1. 删除演示数据源

- 删除 `src/data/mock.ts`（3 个模拟实例、6 个模拟模型、4 个模拟任务）。
- 删除 `src/data/hardware.ts`（双卡 L40S、DGX Spark、DGX Station GB300、单卡／十六卡 RTX 5090 共 5 个演示机型及遥测采样函数）。

### 2. 前端全面真实化（按文件）

- **App.tsx**：删除 localStorage 演示状态（`usePersistentState`）、演示进度 ticker、resetDemo、全部非真实模式分支；实例／模型／任务接口不可用时展示空数组＋离线提示，不再回退演示数据；新增 `backendOnline` 状态（三个业务接口全失败即离线），侧栏状态点与顶栏徽标（已连接／连接失败）联动；所有操作入口统一 `requireBackend` 拦截。
- **HardwareMonitor.tsx**：删除演示机型选择器与遥测采样；只展示真实采集；接口失败显示 amber 告警条（每 2 秒自动重试），不再回退演示机型；`data-telemetry-sample` 改为 `data-hardware-collected`（采集时间戳）。
- **Dashboard.tsx**：指标卡改为真实数据（GPU 卡数与型号、共享仓库真实占用）；问候语按时段动态生成；实例概览空态文案；「最近任务」改传真实任务（修复传错数据源的 bug）。
- **Instances.tsx**：删除模拟打开、Demo 删除说明等非真实分支；自启动开关只读（创建时指定）；新增无实例空态「暂无 ComfyUI 实例」。
- **Models.tsx**：统计卡非真实模式显示「—／仓库接口不可用」，删除写死的 86.4 GB／3.42 TB；删除 Demo 删除说明。
- **System.tsx**：移除不生效的「系统设置」假表单页签与写死的「操作日志」假数据页签；环境报告 7 行全部改为真实硬件采集＋真实 Docker 数据；诊断导出 mode 改 `backend`、去除 Demo 标记。
- **CreateInstanceDialog.tsx**：删除镜像模板／版本等演示概念与 realMode 分支；第二步「模型准备」改为「模型可见性」——共享仓库就绪模型对实例自动可见的只读说明（原 checkbox 选择语义在真实挂载模式下是误导）；`CreateInstanceInput` 类型同步收窄。
- **AddModelDialog.tsx**：删除示例地址预填（models.example.com）与 Demo 文案；名称／地址默认留空。
- **types/index.ts**：`Instance.models`、`TaskItem.modelId/instanceId`、`CreateInstanceInput.template/version/models` 等仅演示用途字段删除；`TaskType` 收窄为真实任务类型。

### 3. 修复的 bug（本轮评审＋实机回归发现）

| # | 问题 | 修复 |
|---|---|---|
| 1 | 首页「最近任务」展示浏览器模拟任务（传错 prop），真实下载任务看不到 | 改传 `displayTasks` |
| 2 | 系统页诊断导出使用模拟实例数据 | 改传 `displayInstances` |
| 3 | App 启动 GPU 列表单次获取无重试，硬件接口冷启动超时（Spark nvidia-smi 首次调用慢于 4s）会导致整会话无法创建 GPU 实例 | 失败每 3 秒自动重试 |
| 4 | 首页问候语固定「下午好」，与实际时间不符 | 按时段动态生成 |

### 4. 回归脚本适配（verify-demo.mjs）

- 移除全部演示分支断言（演示机型切换、模拟创建实例、模拟下载暂停、任务中心模拟同步）；接口不可用时回归直接失败（产品要求真实后端）。
- 新增断言：界面无演示数据标识（遍历 6 个标记文本）、实例列表空态展示。
- 遥测刷新断言改用 `data-hardware-collected`；创建向导两次「下一步」之间等待第二步内容，消除时序竞争。

- **38 项远程回归全部通过**：真实实例生命周期、ComfyUI 预置镜像就绪＋状态代理＋制图徽标＋应用跳转、模型扫描／下载／导入／删除、镜像拉取、任务中心、系统页联调、诊断导出、375px 移动视口、无控制台错误。
