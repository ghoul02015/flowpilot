# 0.0.0.3 变更记录

- 日期：2026-11-04
- 类型：功能／界面／测试
- 需求来源：首页展示更完整的硬件信息，并适配 DGX Spark、DGX Station GB300、单卡及最高十六卡 RTX 5090 等产品形态

## 背景与目标

原首页只有两张简化 GPU 卡片，缺少主机、CPU、内存、存储、功耗等完整信息，也无法正确表达统一内存与多卡服务器。本轮建立可扩展的硬件数据模型和响应式监控面板，为后续真实宿主机采集接口确定展示结构。

## 新增内容

- 新增 `HardwareProfile`、`GpuDevice` 和 `GpuMemoryMode` 类型。
- 新增独立显存 `discrete`、统一内存 `unified`、一致性内存 `coherent` 三种模式。
- 新增五个演示硬件配置：双卡 L40S、DGX Spark、DGX Station GB300、单卡 RTX 5090、十六卡 RTX 5090。
- 首页新增主机名称、操作系统、CPU 型号／核心数／利用率、内存容量／占用、存储容量／占用和挂载说明。
- 每张 GPU 展示设备编号、完整型号、显存或共享内存、计算利用率、核心温度、当前功耗／功耗上限和在线状态。
- 新增 GPU 平均利用率和显存汇总；统一内存不重复累计，GB300 分别表达 CPU 内存、HBM 和一致性地址空间。
- 新增每 2 秒确定性变化的 Demo 遥测，模拟利用率、温度、功耗和显存占用刷新。
- 新增机型选择器，用于验证单卡、双卡、十六卡、x86_64 与 arm64 的界面适配。
- 新增硬件加载、遥测刷新、DGX Spark、DGX Station GB300 和十六卡设备数量的端到端检查。

## 修改内容

- 首页原“GPU 资源”面板替换为全宽“硬件与实时监控”组件。
- 快捷操作调整为三列布局，实例概览、最近任务及其他页面保持不变。
- 多卡场景在宽屏使用四列紧凑卡片，小屏自动调整为两列或单列。
- 高温达到 85°C 时使用警示色；DGX Spark 不展示虚假的独立显存占用，而显示系统统一内存使用率和说明。
- 修复演示机型标签在桌面面板标题中的换行问题。
- 项目、前端、后端健康版本、诊断和镜像版本统一升级为 `0.0.0.3`。
- PRD 首页看板补充逐卡遥测和不同内存架构的展示规则。

## 机型数据设计依据

- NVIDIA DGX Spark 官方用户指南：20 核 Arm、128 GB LPDDR5x 统一系统内存；官方文档同时说明 `nvidia-smi` 的 Memory-Usage 在该机型上不受支持。https://docs.nvidia.com/dgx/dgx-spark/hardware.html
- NVIDIA DGX Station 官方开发指南：72 核 Grace CPU、496 GB CPU LPDDR5X、252 GB GPU HBM3e，以及最高 748 GB 一致性内存。https://docs.nvidia.com/dgx/dgx-station-development-guide/Intro.html
- 上述资料只用于定义 Demo 配置与内存展示方式，实时数值不是官方数据。

## 已知问题与风险

- 尚未接入 `/proc`、`sysfs`、`lsblk`、NVML／`nvidia-smi` 或节点采集服务，不能用于真实硬件监控和告警。
- DGX Spark 与 GB300 的真实可采集指标需要通过目标机器验证，不能假设所有独立显卡指标都可用。
- 多卡实例创建向导仍使用原 Demo GPU 选项，尚未根据首页机型联动生成 1～16 卡资源。
- 十六卡页面较长，本轮采用紧凑网格而未增加分页、折叠或机架拓扑视图。
