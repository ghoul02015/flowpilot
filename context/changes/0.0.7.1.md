## 发现的 Bug 与修复

**Bug**：以 `NONINTERACTIVE=1 nohup` 后台方式运行一键安装脚本时，步骤 2 `$SUDO python3`（配置 Docker Hub 加速）触发 `sudo: 需要密码` 后中止——yl 用户 sudo 需密码，无人值守时无法输入。

**修复**（`install-comfyui-image.sh.tmpl` 的 `need_sudo`）：

- `sudo -n true` 预检凭据；
- 交互模式：`sudo -v` 先缓存凭据，避免下载/构建中途卡提示；
- 非交互模式：明确报错并指引「先交互执行一次或配置 NOPASSWD」。
- `catalog_test.go` 新增 `sudo -n true` 片段断言；`code/scripts/install-comfyui-image.sh` 重新生成。
