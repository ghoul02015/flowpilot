# 0.0.6.1 — 模型市场在线源：双源切换＋全站搜索

日期：2026-11-08
类型：小版本优化（周董指定「小版本优化」，自 0.0.6.0 第四位进位）

## 需求背景

周董评审 0.0.6.0 后提出：1）模型市场要有源选项（ModelScope／HF）并显示连接状态；2）按模型分类分别展示文件；3）模型目录应在线拉取源站列表——源更新后平台再跟着发版维护太麻烦；4）显示名对齐 ComfyUI 官方模板引用名（文件名），尺寸必须展示；5）主流模型如 MiniMax H3 在目录里查不到、也搜不了。

## 源站 API 调研结论（2026-11-08 实测）

- **ModelScope 搜索**：`PUT /api/v1/dolphin/models`，body `{PageSize,PageNumber,SortBy:"Default",Target:"",SingleCriterion:[],Name:<关键词>,Criterion:[]}` → `Data.Model.Models[{Path,Name,ChineseName,Downloads,LastUpdatedTime}]`（经浏览器抓包确认，公开文档未记载）。
- **ModelScope 文件列表**：`GET /api/v1/models/<org>/<repo>/repo/files?Revision=master&Recursive=true`（Recursive 覆盖 Comfy-Org 子目录布局）。
- **HF 镜像**：`GET hf-mirror.com/api/models?search=<q>&limit=N` 搜索；`GET /api/models/<repo>/tree/main?recursive=true` 文件树。
- MiniMax-H3 在 ModelScope 命中 299 个仓库，首位为 Comfy-Org/MiniMax-H3（483 万下载，ComfyUI 官方打包：diffusion_models／text_encoders／vae／loras 子目录齐全，W6A8 16G 优化版适合单卡与 Spark 统一内存）。

## 变更清单

### 后端

- 新增 `internal/catalog/online.go`：`SourcesStatus`（双源并发探测、5s 超时、60s 缓存）、`SearchOnline`（双源归一化仓库结果）、`OnlineFiles`（权重文件过滤 .safetensors/.pth/.pt/.gguf/.bin/.ckpt、大小降序、上限 100 条）；`GuessCategory` 按路径段＋文件名关键词推断入库类别（覆盖 Comfy-Org 布局与 HF 的 FL2VA/text_encoder 中间段）；仓库标识正则校验防路径穿越；msAPIBase/hfAPIBase 包级变量供测试替换。
- `server.go`：新增 `GET /api/v1/sources/status`、`GET /api/v1/models/online/search`、`GET /api/v1/models/online/files`；参数错误 400、上游失败 502。
- `catalog.go`：Manager 增加状态缓存字段；msRequestBase 加 `Recursive=true`；推荐目录新增 5 条 MiniMax H3 条目（FL2VA FP8 20.96GB／W6A8 15.98GB／Qwen3VL NVFP4 15.69GB／视频 VAE 5.21GB／Turbo LoRA 1.96GB，全部 Comfy-Org 仓库，双源同路径）。
- 测试：online_test.go 8 用例全绿（搜索解析、文件列表与类别推断、状态缓存、超时收口、校验错误）。

### 前端

- `AddModelDialog.tsx` 市场面板重构：源切换行（推荐目录／ModelScope／HF 镜像，在线源带连接状态点＋延迟 tooltip）；在线模式搜索仓库 → 展开权重文件列表（文件名 mono 突出＋大小＋类别徽标＋单文件下载）；类型筛选同时作用于内置条目与在线文件；已入库标注覆盖在线文件。
- `api.ts`：`SourceStatus`/`OnlineRepo`/`OnlineFile` 类型与三个新接口封装。
- `App.tsx`：`onlineDownload(file)` 复用下载引擎（类别与地址由后端推断）。

### 回归脚本

- 新增 4 项断言：源状态接口、ModelScope 在线搜索命中 Comfy-Org/MiniMax-H3、推荐目录 MiniMax 条目、界面在线搜索→展开→文件大小展示；总计 46 项。

## 验证结果

- Go 九包 gofmt＋test＋vet 全绿；前端 lint／build 通过。
- Spark 实机（0.0.6.1）：46 项远程回归全部通过，无控制台错误与 4xx/5xx。
- 双源实机状态：ModelScope 317ms 可达、HF 镜像 860ms 可达；MiniMax-H3 搜索首位 Comfy-Org/MiniMax-H3（483 万下载）。

## 已知边界

- HF 镜像仅代理只读搜索与文件列表，gated 仓库文件下载仍需授权（失败属预期）。
- 在线文件类别为自动推断，冷门仓库可能归入 diffusion_models／checkpoints 兜底类，用户可下完手动移动（后续版本支持下载前改类别）。
- HF tree 接口对超大仓库（>1000 文件）分页未做全量拉取，权重文件通常在前 100 条内。
