# 0.0.9.7 变更记录

- 日期：2026-11-11
- 类型：功能（实例数据隔离与历史迁移）
- 需求来源：docs/0.1.0.0版本规划.md 五、`0.0.9.7`——实例数据隔离与历史迁移

## 背景与目标

新建实例全面使用独立 workspace（每实例独立 outputs/workflows/user/config 挂载），旧共享数据通过备份后向导迁移；默认删除实例但保留数据。

## 设计冻结（本版范围）

### 目录结构（新实例）

```text
shared/models/                  # 全局只读模型库（不变）
shared/instance-links/<id>/     # 模型链接目录：从实例名迁移到稳定实例 ID（0.0.9.5 的 UUID）
shared/instances/<id>/
  outputs/                      # 实例独立输出
  workflows/                    # 实例独立工作流
  user/                         # ComfyUI user 数据（含默认输入目录）
  config/                       # 实例专属配置
shared/backups/                 # 数据库与迁移备份（既有）
```

### 后端改造

1. `instance.Manager.Create`：workspace 由后端按 UUID 生成（`shared/instances/<uuid>/`），不接受任意宿主机路径；binds 改为每实例目录；标签新增 `flowpilot.instance.uuid`。
2. `database`：创建实例时先生成 UUID（RecordCreate 已有），Create 流程改为「先 UUID 后容器」，`instance-links` 目录同样以 UUID 命名（`supported` 判定不变，仍看标签）。
3. 重建（同名新容器）沿用 workspace：Delete 默认**保留数据**（只删容器与链接目录），彻底删除需 `purge=true`（删 workspace，需输入实例名在前端确认，后端仍校验 force）。
4. 孤儿 workspace：DB 中 orphan 实例的 workspace 目录有记录可查（0.0.9.5 孤儿机制复用）；提供 `GET /api/v1/instances/workspaces` 列出全部 workspace（含无容器对应的孤儿目录）与容量。
5. 历史迁移（旧共享 outputs/workflows → 实例归属）：本版提供**只读扫描与预览 API**（`GET /api/v1/migration/scan`：扫描 shared/outputs、shared/workflows 的文件数/大小/修改时间分布；`GET /api/v1/migration/preview?instance=`：为指定实例生成迁移计划）与**执行 API**（`POST /api/v1/migration/run`：{instance, scope:[outputs,workflows], mode:copy|move}，先自动备份再执行，校验文件数与字节数）。
6. 迁移执行前后端自动：备份（快照到 backups/migration-<时间戳>/）→ 复制/移动 → 数量与字节校验 → 结果报告；旧共享目录**不删除**（留待管理员确认归档）。

### API 新增

- `GET /api/v1/instances/workspaces`：workspace 清单（uuid、实例名、是否存在容器、容量、最近修改）。
- `DELETE /api/v1/instances/{name}?purge=true`：彻底删除（容器+workspace+链接目录）。
- `GET /api/v1/migration/scan`：旧共享目录扫描。
- `GET /api/v1/migration/preview`：迁移预览。
- `POST /api/v1/migration/run`：执行迁移（备份+复制/移动+校验）。

### UI

- 实例详情弹窗新增「数据」区块：四个目录容量与最近修改。
- 删除弹窗两档：「删除实例（保留数据）」（默认）与「彻底删除（含数据）」需输入实例名确认。
- 系统管理新增「数据迁移」子页：扫描摘要 → 选实例 → 预览（文件数/大小/空间检查）→ 执行 → 结果报告。

### 兼容

- 旧实例（0.0.9.6 及之前创建）：不做原地改造（挂载不可变）；列表标注「共享数据（旧）」，模型关联/迁移能力正常；重建后自动获得独立 workspace（沿用 UUID，历史输出可经迁移向导入库）。
- Spark comfy-01 即为旧实例：回归中演示迁移预览与执行（copy 模式，不中断实例——outputs/workflows 旧共享目录为宿主机 bind，复制只读源不影响运行）。

### 不做

- 不做 user/config 的历史迁移（旧实例无此数据）。
- 不做 NAS/网络存储相关变化（0.0.9.12 范围）。
- 待认领区完整交互留 0.0.9.15 打磨（本版孤儿 workspace 列表已可覆盖核心诉求）。

- **UUID 单源**：容器标签 UUID 为权威；DB 同步/创建均以其为准；删除保留→重建沿用同一 UUID 与 workspace。
