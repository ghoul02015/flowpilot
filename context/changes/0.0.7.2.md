# 0.0.7.2 变更记录

- 日期：2026-11-09
- 类型：功能／重构／测试／部署
- 需求来源：周董「继续优化 ComfyUI 实例模块：新增容器镜像管理、手动构建不同显卡版本镜像、新建实例只能选择已构建镜像，并部署到 Spark 实机验证」

## 背景与目标

0.0.7.0/0.0.7.1 已完成实例镜像可选、一键安装脚本和 DGX Spark 实机验证，但镜像准备动作仍混在「新建实例」弹窗中：配方选择、手动输入、在线拉取、脚本下载与实例资源配置同时出现，环境管理边界不够清晰。

本轮目标：

1. 将本机 Docker 镜像管理独立成实例页子菜单，支持本机镜像增删改、导入和导出。
2. 将手动构建与拉取独立成子菜单，支持按不同显卡配方一键构建 ComfyUI 镜像并查看实时日志。
3. 新建实例向导只允许选择本机已有镜像，构建、拉取、导入等环境准备动作前置到镜像管理模块。

## 新增内容

### 1. 容器镜像管理子菜单

- 实例页新增「容器镜像管理」子菜单。
- 支持读取本机 Docker 镜像列表，展示镜像标签、镜像 ID、大小、创建时间。
- 支持镜像改标签（retag）。
- 支持删除本机镜像标签。
- 支持上传 `docker save` 导出的 tar 文件并通过 Docker API 导入。
- 支持将本机镜像以 tar 流导出下载。

### 2. 手动构建 / 拉取子菜单

- 实例页新增「手动构建 / 拉取」子菜单。
- 支持六套 ComfyUI 构建配方：
  - NVIDIA cu130
  - NVIDIA cu128
  - NVIDIA cu126
  - NVIDIA cu121
  - AMD ROCm
  - CPU
- 支持配置构建镜像名、ComfyUI 分支/标签、pip 源、是否内置 ComfyUI-Manager。
- 支持通过后端 Docker API 后台构建镜像。
- 支持轮询展示构建状态和最近日志。
- 在线拉取镜像入口从新建实例弹窗迁移到该子菜单。

### 3. 后端 Docker 镜像接口

新增接口：

- `DELETE /api/v1/images/local?image=<镜像>[&force=1]`
- `POST /api/v1/images/tag`
- `GET /api/v1/images/export?image=<镜像>`
- `POST /api/v1/images/import`
- `POST /api/v1/images/build`
- `GET /api/v1/images/build`

同时保留：

- `GET /api/v1/images/local`
- `GET /api/v1/images/catalog`
- `GET /api/v1/images/check`
- `POST /api/v1/images/pull`
- `GET /api/v1/images/pull`
- `GET /api/v1/images/install-script`（独立分发脚本仍保留，Web 新建实例不再直接承载）

## 修改内容

- 新建实例弹窗移除「镜像来源三模式」「手动输入镜像名」「在线拉取」「一键安装脚本参数」等环境准备入口。
- 新建实例弹窗改为只选择本机已有镜像；没有本机镜像时提示先去容器镜像管理或手动构建/拉取子菜单准备镜像。
- 实例页描述调整为统一管理本机镜像、手动构建、在线拉取与实例生命周期。
- 后端 HTTP 服务器保留请求头超时，但不再设置固定正文读取/响应写入超时，避免 GB 级镜像导入/导出被 15/30 秒超时中断。
- 构建状态空闲时 `logs` 固定返回空数组 `[]`，避免前端/回归脚本收到 `null`。
- 版本号更新为 `0.0.7.2`。

## 删除内容

- 未删除历史能力。
- 新建实例弹窗中移除了直接构建/拉取/脚本下载入口，但对应能力已迁移到实例页镜像子菜单或保留为后端接口。

## 行为与兼容性影响

- 新建实例必须选择本机已有镜像；如果目标镜像不存在，需要先通过容器镜像管理导入 tar，或通过手动构建/拉取子菜单准备。
- Docker 镜像删除由 Docker Engine 执行约束；镜像被容器使用时默认会失败，避免误删运行环境。
- 镜像导入/导出为大文件长连接能力，管理端仍不应暴露到公网。
- 平台内手动构建镜像依赖 Docker daemon 可访问外网或镜像/源码代理可达；首次构建会下载基础镜像、PyTorch 和 ComfyUI 依赖，耗时较长。

## 已知问题与风险

- 当前版本仍无认证机制，且管理端挂载 Docker Socket，不应暴露到公网。
- 镜像导入/导出与构建均为高权限 Docker 操作，应仅在受信任管理网络使用。
- 平台内手动构建首次耗时较长，且依赖网络质量；如源站不可达会构建失败，日志会保留最近 500 行用于排障。
- Spark 远程完整回归在模型市场下载按钮定位处超时；本轮新增镜像管理和实例创建链路已在该次回归中通过，模型市场超时需后续单独排查。

## 回滚说明

- 代码回滚：`git revert` 本版本提交。
- 运行回滚：重新安装上一版离线包 `flowpilot-0.0.7.1-arm64.tar.gz`，或将 FlowPilot 管理容器切回 `flowpilot-web:0.0.7.1`。
- 数据兼容：本轮不引入数据库迁移；实例、模型、任务和共享目录格式不变。
