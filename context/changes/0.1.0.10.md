## 一、“未检测到 GPU”根因与修复

现象：DGX Spark 硬件页顶部已展示 `1 × NVIDIA GB10`，兼容性检查却提示“未检测到 GPU”；重新刷新后偶发恢复。

根因链：

1. `hardware.NewCollector` 只设置采集路径，**漏设 `cacheTTL`**，生产环境为 0，2 秒合并缓存实际未启用。
2. `Collect` 的并发等待分支在 `cacheTTL=0` 时读不到缓存，直接返回**零值 Report**（无 GPU、无错误）。
3. 页面同时请求 `/hardware` 与 `/hardware/compat`，后者落到等待分支 → 空报告 → 兼容性判定为无 GPU。

修复：

- 构造函数默认 `cacheTTL = 2s`；
- 新增 `last/hasLast`，采集完成后无论是否启用缓存都记录最近报告，等待者读取真实结果；异常场景补采一次；
- `SetCacheTTL` 同时清理最近报告，避免测试与运行态串扰；
- 兼容性检查区分“GPU 采集失败（含错误）”与“确实未检测到 GPU”，提示对应处理建议。

回归测试：

- `TestNewCollectorCachesByDefault`：两次采集只执行一次；
- `TestCollectWaiterGetsRealReportWhenCacheDisabled`：关闭缓存时 6 个并发调用者均拿到含 GPU 的报告。

## 二、品牌视觉

素材来源 `docs/logo/慧浪logo 透明底.png`、`慧浪logo 透明底大版.png`：

- `src/assets/logo-hl.png`：完整横版（缩放到 640×213）；
- `src/assets/logo-mark.png`：自动裁出 HL 标识（200×128，保留透明通道）；
- `public/favicon.png`：64×64 画布居中标识。

色板以 logo 主色 `#921C5F` 为 700，向浅色与深色扩展 50–950；通过 Tailwind `teal` 语义覆盖，使既有 `bg-teal-* / text-teal-* / border-teal-*` 全量切换到品牌色，无需逐文件改类名；另提供 `brand` 别名便于后续使用。中性背景 `oklch` 色相由 220/240 调整到 340，与品红呼应。
