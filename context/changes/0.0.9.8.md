## 设计冻结（本版范围）

### 三层状态

```text
容器：running / stopped / error / unknown（既有 status）
应用：ready / starting / degraded / failed / not_running（新增，健康检查器推导）
队列：idle / running / pending（既有 ComfyStatus 探测）
```

### 健康检查器（internal/health 新包）

- 独立 goroutine 周期运行（启动期 3s／稳定期 10s 滑动；失败指数退避至最长 60s），不依赖页面轮询。
- 探测：仅 running 实例；GET `http://<gateway:port>/system_stats`（复用 comfyGateway 代理路径，超时 3s）；singleflight per 实例。
- 状态机：探测成功→ready（首次成功写 ready 事件）；连续 3 次失败→degraded→failed；容器停止→not_running；创建后容器 running 但未探测成功→starting。
- 事件：状态迁移写入 `instance_events`（迁移 003）；**恢复也记录**（degraded/failed→ready）。
- 有界并发：同时最多 8 个实例探测。

### 迁移 003：instance_events

```sql
CREATE TABLE instance_events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  instance_uuid TEXT NOT NULL,
  name TEXT NOT NULL,
  ts TEXT NOT NULL,
  kind TEXT NOT NULL,        -- ready / degraded / failed / recovered / stopped / started / created / deleted / probe_error
  detail TEXT NOT NULL DEFAULT '',
  latency_ms INTEGER NOT NULL DEFAULT 0
);
CREATE INDEX idx_events_uuid_ts ON instance_events(instance_uuid, id);
```

### 操作互斥

- instance.Manager 增 per-name 操作锁：Start/Stop/Restart/Delete/Create 对同一实例互斥（操作进行中返回 409 类错误「操作进行中」）。

### 启动超时

- 应用 starting 超过 180s（FLOWPILOT_START_TIMEOUT 可配）→ failed 事件（保留容器与日志，不删不重建）。

### 停止/重启队列保护

- Stop/Restart 前探测队列（queue_running+queue_pending>0 时响应仍执行但返回 `queueWarning` 字段；前端 toast 提示）。阶段 1 不阻断。

### 重建差异预览

- `POST /api/v1/instances/{name}/rebuild/plan`：对比 DB 期望配置（instance_configs.spec_json）与当前容器标签，输出差异字段列表（镜像/GPU/端口/容器端口/自动启动）＋数据目录沿用说明（0.0.9.7 workspace 复用）＋中断提示。
- 前端重建入口（旧实例模型关联弹窗的"删除并按原参数重建"提示处 + 实例操作菜单）展示差异表。

### API 新增

- `GET /api/v1/instances/{name}/health`：三层状态＋最近 3 次探测延迟＋最近事件。
- `GET /api/v1/instances/{name}/events?limit=`：事件时间线（倒序）。
- `POST /api/v1/instances/{name}/rebuild/plan`：重建差异预览。
- 既有 `POST /api/v1/instances/{name}/{start|stop|restart}` 响应增加 `queueWarning?`；互斥冲突返回 409 `{code:"busy"}`。

### UI

- 实例列表：「应用健康」与「容器状态」两列；健康徽章（就绪/启动中/降级/失败/停止）；队列徽章（运行 n/排队 n）。
- 「打开」按钮仅应用 ready 时主色；其余状态显示诊断入口（日志）。
- 实例详情弹窗顶部健康条：三层状态＋最近事件 3 条＋「查看全部事件」。
- 事件子视图：时间线列表。
- 重建差异预览弹窗：差异表格＋workspace 沿用说明。

### 不做（记录）

- /object_info 深度诊断与错误码全量分类（本版 probe_error 统一记录 detail；0.0.9.13 硬件诊断扩展）。
- 20+ 实例压测基线（记风险，0.1.0.0 总验收补）。
- 创建返回关联任务（0.0.9.9 统一任务制一并处理）。
