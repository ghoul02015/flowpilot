# 0.1.0.2 变更记录 — ComfyUI 版本固定与可追溯

- 日期：2026-11-11
- 类型：功能（镜像供应链与版本可追溯）
- 需求来源：用户反馈构建参数只显示 `ComfyUI 版本：master`，无法确认实际版本
- 发布包：`flowpilot-0.1.0.2-arm64.tar.gz`（MD5 `248e31c7afd5171562660bb314a3bd07`）

## 问题与根因

1. `/comfyui-refs` 只读取 GitHub Tags 名称并固定追加 `master`，没有 commit SHA、发布时间、Release 状态。
2. Dockerfile 使用 `git clone --branch "$COMFYUI_REF"`，选择 master 时每次构建都可能拉取不同代码。
3. 镜像只记录 `flowpilot.comfyui.ref=master`，无法回答“几个月前这个镜像到底是什么版本”。
4. 网络异常时旧接口会静默回退 master，构建结果不可确认。
5. 独立安装脚本同样按分支克隆，且缺少 `flowpilot.kind=comfyui` 标签，平台创建实例时会被可信镜像校验拒绝。

## 新增与修改

### 版本解析服务

- 新包实现 `VersionResolver`，联合官方 GitHub：
  - `/releases`：正式 Release 与 Prerelease。
  - `/tags`：全部版本标签与 commit SHA。
  - `/branches/master`：master 当前 commit。
  - `/commits/{ref}`：自定义标签／分支／commit 核验。
- 区分：
  - 正式 Release；
  - 仅标签版本；
  - 开发分支；
  - 自定义 commit。
- 默认选择最新稳定 Release，不把“最新 Tag”误认成“最新稳定 Release”。
- 10 分钟缓存、ETag/If-None-Match、磁盘缓存、在线失败降级、GitHub 限流提示。
- 无缓存且在线失败时不回退 master。
- 支持 `FLOWPILOT_GITHUB_TOKEN` 提高限流额度；`FLOWPILOT_GITHUB_API_BASE` 供受控镜像/测试使用。

### API

- `GET /api/v1/images/comfyui-versions`：版本目录，支持 `refresh=1`。
- `POST /api/v1/images/comfyui-resolve`：解析 ref/kind/commit。
- 保留 `GET /api/v1/images/comfyui-refs` 兼容旧客户端。

### 构建固定版本

- `BuildParams.Source` 保存服务端解析后的不可变源码坐标：
  - 原始 ref、版本号、commit、commit 时间、发布时间、渠道、仓库、解析时间。
- 服务端在提交构建、下载构建脚本、生成安装脚本时统一核验；客户端提交的版本不能绕过服务端。
- Dockerfile 改为：
  - `git init` + `git fetch --depth 1 origin "$COMFYUI_COMMIT"`；
  - `git checkout --detach`；
  - `test "$(git rev-parse HEAD)" = "$COMFYUI_COMMIT"`。
- 拉取通道：官方 GitHub → gh-proxy → gitclone；Spark 实测官方与 gitclone 被网络策略拦截，gh-proxy 可用。
- 构建任务持久化 Source，重试与后续追溯沿用相同 commit。

### 镜像元数据

- OCI 标签：
  - `org.opencontainers.image.revision`
  - `org.opencontainers.image.version`
  - `org.opencontainers.image.source`
- FlowPilot 标签：
  - `flowpilot.comfyui.ref`
  - `flowpilot.comfyui.version`
  - `flowpilot.comfyui.commit`
  - `flowpilot.comfyui.channel`
  - `flowpilot.comfyui.commit_date`
  - `flowpilot.comfyui.published_at`
  - `flowpilot.comfyui.resolved_at`
  - `flowpilot.comfyui.repository`
- 镜像内 `/opt/flowpilot/comfyui-source.json` 保存机器可读源码档案。

### UI

- 构建弹窗新增产品化版本选择器：
  - 默认最新稳定 Release；
  - Release / 仅标签 / master / 自定义四类来源；
  - 预发布版本默认隐藏；
  - 版本解析确认卡展示版本、完整 commit、发布日期和“本次构建固定到该 commit”；
  - 版本接口异常、缓存、stale 与警告状态可见。
- 镜像列表版本显示：
  - 新镜像：`v0.45.0 · 989d93d` 或 `master@4d64a8b`；
  - 旧镜像：`master（未固定提交）`／`未记录版本`，不伪造版本号。
- 未选择／解析版本时禁止开始构建和下载构建脚本。

### 独立脚本

- 安装脚本模板与仓库独立脚本同步：
  - 构建时固定 commit；
  - 支持镜像通道依次重试；
  - 生成版本标签与源码档案；
  - 补齐 `flowpilot.kind=comfyui`，保证平台可识别。
- Web 构建脚本、独立安装脚本、镜像中心在线构建三个入口保持一致。

## 已知边界

- CPU 验证镜像未完成最终打包（依赖下载链路停滞）；固定 SHA 获取与 Dockerfile 源码阶段已通过。GPU 镜像构建仍建议在正式配方网络环境下补一次完整验收。
- 本次只固定 ComfyUI Core；ComfyUI-Manager、PyTorch 和基础镜像仍按现有配方策略，因此不是整镜像逐字节可复现。
- 旧镜像不回溯修改标签；显示“未固定提交”而不是猜测。
- 已存在的旧构建任务没有 Source，重启/中断后不可重试；新任务持久化完整 Source。
- GitHub API 无 Token 时受匿名限流约束，目录缓存 10 分钟。
