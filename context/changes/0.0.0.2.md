# 0.0.0.2 变更记录

- 日期：2026-11-04
- 类型：修复／功能／部署／测试
- 需求来源：新建实例弹窗透明问题，以及开始 0.0.0.2 后端基础构建的要求

## 背景与目标

优先解决新建实例弹窗后方内容穿透的问题，再在保留 Web Demo 交互的基础上建立轻量 Go 后端，让系统管理页读取真实 Docker Engine 和容器信息，形成第一个前后端联调闭环。

## 新增内容

- 新增 `code/backend/`，使用 Go 标准库实现管理服务，无第三方后端依赖。
- 新增 Unix Socket Docker 客户端，提供真实 `/info`、`/version` 和 `/containers/json?all=1` 摘要。
- 新增 `GET /api/v1/health`、`GET /api/v1/system/info`、`GET /api/v1/docker/info`、`GET /api/v1/docker/containers`。
- 新增 SPA 静态文件服务、API JSON 404、安全响应头、请求超时和优雅关闭。
- 新增临时 Unix Socket 假 Docker 服务测试，以及健康接口和未知 API 测试。
- 新增前端 `src/api.ts`，统一请求健康、Docker Engine 和容器列表。
- 系统页显示后端连接状态、真实 Docker 版本和容器统计，连接失败时明确回退到 Demo。
- 诊断 JSON 新增后端与 Docker 运行快照。
- 端到端测试新增健康接口版本、真实 Docker 信息、系统页联调及弹窗不透明度断言。

## 修改内容

- 将全局主题变量从完整 OKLCH 颜色改为 shadcn/Tailwind 配置所需的 HSL 通道；直接使用变量的样式同步包装为 `hsl(var(...))`。
- 同步修复 Sonner Toast 的背景、文字和边框变量使用方式。
- 系统页对真实 Docker 数据和 Demo 硬件／GPU 数据分别标识，避免将管理服务容器信息误称为宿主机完整 GPU 检测。
- Docker 镜像改为 Node 前端构建、Go 后端编译、Alpine 运行三阶段，运行服务由 Nginx 改为 `flowpilotd`。
- `demo-docker.sh up` 继续重建同名容器，镜像升级为 `flowpilot-web:0.0.0.2`，映射 `18080:18080` 并挂载 Docker Socket。
- 项目、前端、诊断、PRD 和协作规则中的当前版本统一升级为 `0.0.0.2`。

## 删除内容

- 无文件删除。旧版 `code/deploy/nginx.conf` 保留作历史参考，但 `0.0.0.2` 镜像不再使用 Nginx。

## 行为与兼容性影响

- `http://localhost:18080` 继续作为统一入口，原页面路径和浏览器 Demo 数据格式不变。
- 新增 `/api/v1/` 后端接口；未命中的 API 返回 JSON 404，不再回退到前端页面。
- 一体化容器需要挂载 `/var/run/docker.sock` 才能读取真实 Docker 信息；未挂载时页面会显示连接失败并保留明确标记的 Demo 数据。
- 当前 Docker 接口仅提供读取能力，不会新建、启动、停止或删除真实容器。
- 旧版 Nginx 配置不参与新镜像运行，健康检查改为 `/api/v1/health`。
