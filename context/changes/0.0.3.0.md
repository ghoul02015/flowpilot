# FlowPilot 0.0.3.0 变更记录

日期：2026-11-08
主题：下载任务引擎——模型 URL 下载真实化（断点续传＋SHA256 校验），任务中心接入真实任务流

## 背景

按 0.0.2.0 遗留事项推进：模型 URL 下载从 Demo 模拟接入真实下载引擎，打通"添加模型→下载→入仓→实例可用"全链路，任务中心同步接入真实任务。

## 后端

### `internal/download/download.go`（新增）

- 任务模型：内存存储（重启清空，仓库文件不受影响），状态机 running→paused／completed／failed／cancelled。
- 断点续传：分片写入 `<仓库>/.downloading/<id>.part`；暂停保留分片，继续时发 `Range: bytes=N-`（206 续传、200 重下、416 直接收尾）。
- SHA256 校验：可选 64 位十六进制校验值，完成后比对，失败不入库并保留分片供重试。
- 归档：完成后 `rename` 到 `<仓库>/<类别>/<文件名>`，类别即 ComfyUI 子目录（other 落根目录）。
- 校验：URL 仅 http/https、类别 `^[a-z0-9][a-z0-9_-]{0,63}$`、文件名拒绝路径分隔与隐藏文件、仓库同名文件冲突拦截。
- 取消清理分片；仅进行中的任务占用目标路径（本轮修复：早期版本 completed 记录会永久阻塞同目标重下）。

### `internal/server/server.go`

- 新路由：`GET/POST /api/v1/downloads`、`POST /api/v1/downloads/{id}/{action}`（pause/resume/cancel/retry）、`DELETE /api/v1/downloads/{id}`；错误映射 400／404／409。
- `Version` 提升为 `0.0.3.0`。

### 测试

- download 包 5 用例（httptest 支持 Range 与限速源）：完整下载＋SHA256 校验入库、中途暂停断点续传内容一致、校验失败不入库、参数校验与同名冲突、取消清理分片。七包 `go test ./...` 全过。

## 前端

- `api.ts`：`DownloadTask` 类型与 `getDownloads`／`createDownloadApi`／`downloadActionApi`／`deleteDownloadApi`；`modelTypeToCategory` 界面类型→仓库子目录映射。
- `App.tsx`：下载任务 3 秒轮询；模型列表合入进行中下载（`dl-` 前缀 id，running→downloading 映射）；任务中心切换为真实下载任务（进度、取消、重试）；侧栏任务角标按真实任务统计。
- `components/AddModelDialog.tsx`：真实模式文案（断点续传说明）、名称可留空从 URL 推导；本地导入暂提示放入共享目录。
- `pages/Models.tsx`：下载任务条目删除弹窗文案区分（移除任务 vs 删除文件）。
- `verify-demo.mjs`：真实分支新增 URL 下载全链路（API 状态为准等待完成入库，消除界面轮询合并行的时序干扰）与任务中心真实任务断言。
