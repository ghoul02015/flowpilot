# 0.1.0.9 模型中心交互优化

- 版本：0.1.0.9
- 日期：2026-11-16
- 依据：用户对 0.1.0.8 在线获取、套装进度与未完成下载的反馈
- 范围：模型中心在线获取布局、套装查看进度跳转、下载任务操作与模型清单导出
- 不在范围：新增下载协议、改变断点续传实现、新增业务模型或数据库 schema

## 一、在线获取界面

| 项 | 0.1.0.8 | 0.1.0.9 |
| --- | --- | --- |
| 推荐目录布局 | 单列，卡片紧凑 | ≥1280 px 双列，卡片内边距加大 |
| 列表可视高度 | 320 px | 58vh（约 500 px，1080p 下可见 6 条） |
| 名称字号 | 14 px | 15 px |
| 类型／大小徽章 | 11 px | 12 px |
| 描述 | 单行截断 | 两行（line-clamp-2） |
| 下载按钮 | 小号 | 标准尺寸 |

在线仓库搜索结果区域同步提升到 58vh；添加模型弹窗内仍为单列，避免弹窗过宽。

## 二、套装「查看进度」

原行为：点击「查看进度」打开套装详情并弹出安装向导，需手动关闭向导才能看到进度。

现行为：

1. 读取套装详情，取当前安装项或任一已派生子任务的项；
2. 存在子任务时直接跳转 `/tasks/:id`，展示该下载任务的状态、进度与失败原因；
3. 排队中尚无子任务时打开套装详情抽屉（不弹向导），可看到排队状态；
4. 详情读取失败时同样退回详情抽屉，避免无反馈。

## 三、未完成下载操作

模型中心「未完成的下载」组按状态提供操作：

| 状态 | 操作 |
| --- | --- |
| 下载中 | 暂停、取消 |
| 已暂停 | 继续（断点续传）、取消 |
| 失败／已取消 | 重试、删除记录 |
| 就绪（本地） | 复制仓库路径、删除 |
| 就绪（网络存储） | 复制仓库路径、本地化 |

模型列表头部新增「导出清单」，按当前筛选结果导出 CSV，字段为名称、类型、大小、状态、来源、仓库路径、更新时间；文件带 UTF-8 BOM，Excel 直接可读。复制路径在非安全上下文（局域网 http）下回退到临时 textarea，避免 Clipboard API 不可用。

## 四、验证

1. **断点续传端到端**：本地 32 MB 文件 + 支持 Range 的限速服务（64 KB／120 ms）。
   - 下载中暂停：4.7 MB，暂停后保持稳定；
   - 点击继续：从 4.7 MB 接续，未回到 0；
   - 完成后字节数为 33,554,432。
2. **取消后重试**：取消记录后点击重试，任务重新进入运行并完成。
3. **自动化**：`e2e-audit` 增加双列布局、列表高度、CSV 导出、重试入口、复制路径五项断言，本地 106 项全通过；`e2e-smoke`、`e2e-routes`、`vitest` 12 项、后端 16 包全绿。
4. **Spark 实机**：安装 0.1.0.9 后复跑审计与两套回归，结果记录在交付说明。

## 五、回滚

- 数据库 schema 未变更；回滚只需恢复上一版本镜像。
- 新增 UI 操作复用既有下载接口（`/downloads/:id/pause|resume|cancel|retry`），不改变任务状态机。
