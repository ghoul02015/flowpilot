# 0.0.6.2 — 修复：全词搜索空结果＋弹窗横向溢出

日期：2026-11-08
类型：小修复（周董实测反馈，自 0.0.6.1 第四位进位）

## 问题与排查

### 问题 1：搜索「Minimax」空结果，搜「Mini」反而有结果

排查过程：
1. curl 直连 ModelScope 搜索 API 验证大小写敏感性：Minimax／minimax／MiniMax／Mini 全部正常返回（871／2726 条），大小写不敏感。
2. 通过 Spark 后端完整链路连测 6 次「Minimax」：6/6 返回 20 条，无 429／超时。
3. 结论：后端与源站链路稳定，最可能是 ModelScope 风控间歇返回 `Code=200` 但空列表（数据中心 IP 常见）。

修复：
- 后端 `searchModelScope` 空结果自动等待 600ms 重试一次再收口（`online.go`）。
- 前端空结果提示改为「未找到相关仓库。源站分词对长词更严格，可尝试更短的关键词（如把「MiniMax-H3」换成「MiniMax」），或切换到另一个源再试。」

### 问题 2：弹窗文字／组件超出 UI 右边界

排查过程（Playwright 复现脚本实测数据）：
- 弹窗 rect 宽 672px，但 scrollWidth 845px，全部直接子元素被撑到 821px——溢出约 150px，与截图完全吻合。
- 根因：shadcn `DialogContent` 使用 `grid` 布局，grid 子项默认 `min-width:auto`，长 mono 文件名（truncate＝white-space:nowrap，min-content 为全文宽）把单列 track 撑宽，整个内容盒溢出弹窗右边界。

修复：
- `dialog.tsx` DialogContent 类名追加 `[&>*]:min-w-0`——所有弹窗的 grid 子项允许收缩到轨道宽度内，所有弹窗全局生效。
- `AddModelDialog` 市场面板根容器追加 `min-w-0` 双保险。
- 修复后复测：scrollWidth=670=clientWidth，溢出归零。

## 回归与验证

## 影响面

- DialogContent 的 `[&>*]:min-w-0` 作用于全部弹窗（新建实例、删除确认、添加模型等），均为收缩方向修正，不影响正常布局。
- 后端搜索重试仅增加空结果场景 600ms 延迟，正常搜索无感知。
