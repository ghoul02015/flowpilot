# 0.0.9.11 变更记录

- 日期：2026-11-11
- 类型：安全（模型中心、安全与资产治理·精简版）
- 需求来源：docs/0.1.0.0版本规划.md 九

## 范围决策（精简）

模型元数据体系（许可/审核状态/来源记录）与空间治理留后续；本版交付三大安全约束（服务端强制）。

## 新增内容

- **SSRF 防护**：下载 URL 创建时解析目标全部 IP，阻断 loopback/私网/链路本地/未指定地址；内网模型源白名单 `FLOWPILOT_DOWNLOAD_ALLOW_HOSTS`（逗号分隔，显式放行+审计日志）。`download.guardSSRF`。
- **服务端删除保护**：`DELETE /api/v1/models` 存在运行中实例时 422（列出实例名；前端禁用仅为体验，安全约束服务端强制）。
- **导入白名单**（既有 importDirs 校验保留，确认覆盖路径穿越场景）。

## 测试与验证

- 后端 14 包全绿（download 测试经 TestMain 白名单 127.0.0.1 适配）。
- 本机 E2E **83 项全部通过**（新增 SSRF 内网拦截断言；localhost 自下载经 demo 白名单）。
- **Spark 实机**：运行实例（comfy-01）删除模型 422、内网 IP 下载 400 拦截、comfy-01 无损；0.0.9.11 healthy。

## 已知问题与风险

- DNS 重绑定（TOCTOU）未防护（创建时校验+下载时实际连接可能不一致）——0.0.9.16 复核（需传输层 IP 钉扎）。
- 模型元数据（来源/许可/审核）与 hash 全量扫描留 0.0.9.15。

## 回滚说明

- 回滚 0.0.9.10 直接部署旧镜像；新约束消失但不影响数据。
