# 0.0.0.4 变更记录

- 日期：2026-11-07
- 类型：部署／测试／修复
- 需求来源：周董要求在 DGX Spark 物理机（实际地址 `192.168.0.77`）部署验证，并要求一键卸载机制，不能污染硬件机器环境

## 背景与目标

FlowPilot 将预装在慧浪智算 GPU 服务器上，交付时必须满足：

1. 一条命令完成离线安装，不依赖公网拉取镜像。
2. 不修改系统软件包、不需要 sudo，便于客户机器环境合规。
3. 一键卸载后环境完全还原，不残留容器、镜像和文件。
4. 目标机器上已有业务容器（`comfyui-h3`）不受影响。

## 新增内容

- `code/scripts/package-release.sh`：构建 `flowpilot-web:0.0.0.4` 并导出 arm64 镜像包，生成约 6.7 MB 的离线发布包（`.tmp/release/`，不纳入 Git）。
- `code/scripts/install.sh`：用户目录安装，默认 `~/.local/share/flowpilot`；检查 Docker、Socket、镜像包和端口；启动容器并等待 healthy；容器带 `flowpilot.managed=true`、`flowpilot.version` 标签；支持 `FLOWPILOT_HOME`、`FLOWPILOT_CONTAINER`、`FLOWPILOT_PORT` 环境变量覆盖，便于多实例和测试。
- `code/scripts/uninstall.sh`：需 `--yes` 或交互输入 `yes`；删除容器后按标签判断是否还有其他 FlowPilot 容器，有则保留共享镜像，无则删除镜像；安装目录白名单保护（只允许 `~/.local/share/flowpilot*`）。
- `code/scripts/deploy-remote.sh`：通用远程部署辅助脚本 `deploy-remote.sh <user@host> <发布包> [端口]`。

## 修改内容

- 版本统一升级为 `0.0.0.4`：`VERSION`、后端 `server.go`、前端页面、`package.json`／`package-lock.json`、`demo-docker.sh`、`verify-demo.mjs` 健康检查版本。
- 卸载脚本的镜像共享判断由「镜像 ID 比对」改为「容器标签判断」：实测发现 buildx 多架构镜像下容器记录的是 manifest digest，与 `docker image inspect` 返回的 config digest 不一致，导致共享镜像被误删；标签方案不受 digest 差异影响，已实测修复。

## 删除内容

## 行为与兼容性影响

- 安装不再需要 root／sudo，不写 `/usr`、`/etc` 等系统目录。
- 卸载只影响 FlowPilot 自身资源；`comfyui-h3` 等无关容器、Docker 网络、系统包均不受影响。
- 镜像标签策略只对新安装的容器生效；旧版本容器无标签，卸载时按“最后一个 FlowPilot 容器”处理。

## 测试与验证

远程目标机实测环境：

- 主机名 `spark-6558`，Ubuntu 24.04.4 LTS，aarch64
- GPU：NVIDIA GB10（统一内存，`nvidia-smi` 显存字段为 N/A），驱动 580.159.03
- Docker Server 29.2.1，API 1.53；已有容器 6 个，其中 `comfyui-h3` 在运行

验证步骤与结果：

1. 地址修正：周董提供的 `192.68.0.77` ping 与 SSH 均超时，确认实际地址为 `192.168.0.77`。
2. 环境盘点后先 `docker pause comfyui-h3` 保护原业务容器，全部验证结束后 `unpause` 恢复，最终状态 `running Paused=false`。
3. 离线包上传→解压→`install.sh`：安装成功，容器 `running healthy`，`/api/v1/health` 返回 `{"service":"flowpilotd","status":"ok","version":"0.0.0.4"}`。
4. `/api/v1/docker/info` 返回真实 Engine 信息（Name=spark-6558、NCPU=20、MemTotal≈121.7 GiB 等）。
5. `FLOWPILOT_DEMO_URL=http://192.168.0.77:18080 npm run test:demo`：18 项全部通过（首次安装后一轮；标签修复重装后又一轮，同样全过）。
6. 沙箱卸载保护：独立容器 `flowpilot-uninstall-test`（端口 18081、独立目录）安装并卸载后，沙箱容器与目录已删除，共享镜像保留，生产容器 `running healthy`。
7. 完整卸载：`flowpilot-uninstall --yes` 删除容器、镜像、安装目录全部确认；随后用同一离线包重装，恢复 `running healthy`。
8. 本地检查：`bash -n` 全部脚本、前端 `lint`／`build`、后端 `go test ./...` 与 `go vet ./...` 均通过。

## 已知问题与风险

- 首页硬件监控仍为 Demo 模拟数据；DGX Spark 的 `nvidia-smi` 显存字段为 N/A（统一内存），后续接真实 `/api/v1/hardware` 时需单独适配。
- 当前版本无认证，`18080` 端口不应暴露到公网。
- 卸载保护依赖容器标签，手工 `docker run` 启动的 FlowPilot 镜像容器不带标签，卸载时镜像会被删除（属预期边界情况）。

## 回滚说明

- 远程回滚：执行 `~/.local/share/flowpilot/bin/flowpilot-uninstall --yes` 即可完全清理；`comfyui-h3` 未受影响无需回滚。
- 代码回滚：`git revert` 本次提交，镜像回到 `flowpilot-web:0.0.0.3`。
