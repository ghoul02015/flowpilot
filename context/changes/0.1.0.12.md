# 0.1.0.12 变更记录

- 日期：2026-11-16
- 类型：UI 优化（去粉色化＋结构清晰度）
- 需求来源：周董反馈「把背景的粉色调整下，不用完全参考 logo 色系；logo 位能提醒软件名和 logo 即可；UI 结构更清晰点」。

## 背景与目标

0.1.0.11 浅色化后，页面底/顶栏/卡片仍带品牌品红暖调（oklch 340 色相），整体偏粉。本轮将背景统一为中性色，品牌品红收敛为纯强调色，同时收敛 logo 区信息。

## 修改内容

- `ConsoleLayout.tsx`：页面底 `bg-[oklch(0.975_0.007_340)]` → `bg-slate-50`；顶栏 `bg-[oklch(0.995_0.003_340)]/95` → `bg-white/95`；logo 区改为上下结构——完整 logo（h-8）＋「FlowPilot · ComfyUI 一体化管理平台」小字（text-slate-400），仍整区可点回首页。
- `components/common.tsx`（Panel 面板）：卡片底 `bg-[oklch(0.995_0.003_340)]` → `bg-white`，灰底白卡层次更清晰，惠及全站所有面板。

- 本地视觉验证（2026-11-16）：`vite preview`＋Playwright 代理 /api 至 Spark 真实后端登录，截图确认中性灰底、白卡片层次、logo＋软件名渲染正确；预览与临时脚本已清理。
