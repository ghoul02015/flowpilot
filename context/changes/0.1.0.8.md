# 0.1.0.8 真实路由与 UI 信息架构收敛

- 版本：0.1.0.8
- 日期：2026-11-14
- 依据：`docs/0.1.0.7-0.1.0.8开发规划与排期.md` 第九至十一章
- 范围：路由表、控制台布局、实例与任务详情路由化、模型三页签、系统四分组、镜像搜索与分页、窄屏与可访问性
- 不在范围：新增业务功能、WebSocket、状态管理框架、数据库 schema 变更、告警中心、RBAC/SSO

## 一、路由契约

新增 `src/lib/routes.ts` 作为唯一权威定义，页面路径、标题、参数白名单与登录回跳校验都集中于此。

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/dashboard` | 首页看板 | 保留原有卡片、快捷操作与图表 |
| `/instances` | 实例列表 | 删除只有一个「实例列表」的冗余页签 |
| `/instances/:name` | 实例详情 | 概览、应用健康、最近事件与生命周期操作 |
| `/images` | 镜像中心 | 搜索、其他镜像默认折叠、客户端分页 |
| `/models?tab=local\|online\|bundles` | 模型中心 | 缺省 `local`，非法值回退且不报错 |
| `/tasks?type=&status=&q=&page=` | 任务列表 | 仅白名单参数进入 URL，页码越界自动回退 |
| `/tasks/:id` | 任务详情 | 字段、进度、失败原因、镜像日志与操作 |
| `/hardware` | 硬件管理 | 不变 |
| `/system/:section` | 系统管理 | 八类分区归入四组，非法分区显示可恢复提示 |
| `/`、`/login`、`/setup` | 重定向 | 已登录状态回看板 |
| 未匹配路径 | 404 | 提供返回看板入口，不渲染空白页 |

`pagePath(page, { focus })` 把旧的页面状态跳转映射为真实地址：实例定位进入 `/instances/:name`，任务定位进入 `/tasks/:id`，模型定位只接受合法页签。`safeNextPath()` 拒绝协议、协议相对地址、反斜杠与 `/login`、`/setup`，避免开放重定向。

## 二、布局与数据层

- 新增 `src/layouts/ConsoleLayout.tsx`：侧栏、顶栏、移动端抽屉、全局弹窗与 `<Outlet />`。
- 新增 `src/state/app-data.tsx`：认证引导、按页面启用的轮询、业务写操作与全局弹窗状态集中在此，页面只订阅需要的数据。
- `src/App.tsx` 收敛为认证入口：`checking → setup → login → ready`；未登录访问站内页面先记录目标地址再跳登录，登录成功回到原始目标。
- `src/router.tsx` 集中路由表，页面使用 `React.lazy` + `Suspense` 按需加载，加载态高度稳定。
- 导航使用 `NavLink` 并输出 `aria-current="page"`，键盘可直接遍历。

## 三、详情路由化

实例详情 `src/pages/InstanceDetail.tsx`：

- 概览、应用健康、最近事件、GPU／端口／挂载与容器名；
- 启停、重启、删除（保留数据／彻底删除）与打开 ComfyUI；
- 日志与模型关联复用原弹窗；
- 健康 5 秒、事件 15 秒，随路由卸载停止；
- 实例不存在、加载中分别呈现，不显示其他实例的数据。

任务详情 `src/pages/TaskDetail.tsx`：

- 使用 `GET /api/v1/tasks/:id` 读取单任务，活跃 2 秒、终态 15 秒；
- 暂停、继续、重试、取消、删除记录与镜像日志；
- 任务不存在时给出兜底页面。

列表页只保留筛选与批量操作，`详情` 按钮改为跳转，不再复制一份弹窗逻辑。

## 四、信息架构调整

模型中心拆为「本地仓库｜在线获取｜组合套装」三页签。`MarketPanel` 从 `AddModelDialog` 导出复用，保留推荐目录、ModelScope、HF 镜像、仓库展开、文件下载与已入库判断；「添加模型」弹窗仍只负责 URL 下载与本地导入。

系统管理八类页签归为四组：

| 分组 | 分区 |
| --- | --- |
| 环境与兼容性 | 环境检测 |
| 存储与数据 | 网络存储、数据底座、数据迁移、存储与备份 |
| 安全与审计 | 安全与会话、操作审计 |
| 维护与支持 | 诊断与关于 |

组内二级导航与 `/system/:section` 双向同步，各面板仍按需挂载。

镜像中心新增名称／标签／镜像 ID 搜索，「机器其他镜像」默认折叠，ComfyUI 镜像每页 8 个标签，分页与搜索只影响展示，操作对象始终取当前行。

## 五、关键修复

1. **深链接资源 404**：`vite.config.ts` 的 `base` 由 `'./'` 改为 `'/'`。原配置生成相对资源路径，访问 `/system/security` 刷新时会把 `assets/*.js` 解析到 `/system/assets/*`，服务端回退 `index.html` 导致 MIME 错误与白屏。
2. **任务页窄屏溢出**：筛选输入由固定 `w-52` 改为窄屏 `w-full`，消除 375 px 下 49 px 横向溢出。
3. **任务筛选写 URL 时的抖动**：搜索防抖只在内容真正变化时写回，翻页与筛选统一走查询参数，避免污染历史记录。

## 七、回滚

1. 发布包保留上一版本镜像（安装脚本输出 `保留旧镜像` 提示），可直接用上一版本镜像重建容器。
2. 数据库 schema 未变更，回滚不需要迁移。
3. 路由改造只影响前端地址；旧版本仍可通过根路径进入看板。若仅需临时恢复，可回退镜像而保留数据目录。
