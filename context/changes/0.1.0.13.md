# 0.1.0.13 变更记录

- 日期：2026-11-16
- 类型：UI 优化（logo／按钮配色／弹窗布局）
- 需求来源：周董三点反馈（附截图）：① logo 太小看不清，登录页与界面同步放大；② 添加模型弹窗信息布局不利于视觉；③ 按钮全是 logo 同色系红，晃眼，配色与 logo 搭配但不同色。修改后部署 Spark，版本 0.1.0.13。

## 修改内容

- `index.css`：`btn-primary` 由 `bg-teal-700`（品牌品红）改为 `bg-slate-900 hover:bg-slate-700 active:bg-slate-800`，品红收敛为小面积强调（导航选中、链接、徽章）；全站主按钮（新建实例、添加模型、开始下载/导入、登录、在线搜索等）统一生效，无需逐处改动。
- `ConsoleLayout.tsx`：侧栏 logo `h-8` → `h-11`。
- `LoginPage.tsx`：登录页 logo `h-14` → `h-20`。
- `SetupPage.tsx`：初始化页 logo `h-9` → `h-12`。
- `AddModelDialog.tsx`（MarketPanel，弹窗与模型中心「在线获取」页签共用）：
  - 卡片由单行压缩布局改为三段式：头部「完整名称＋文件名（等宽小字）居左、操作居右」→ 属性行（类型徽章／大小·可达性徽章／HF 备选链接）→ 描述（两行收起）。
  - 名称不再截断（去掉 truncate，允许完整显示）；下载按钮由 btn-primary 大实心改为 `btn-secondary` 小尺寸描边（px-3 py-1.5 text-xs），整屏不再一排品红大按钮。
  - `data-testid="market-entry-*"`、aria-label「下载 <名称>」等回归锚点全部保留。
