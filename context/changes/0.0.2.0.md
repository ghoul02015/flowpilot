# FlowPilot 0.0.2.0 变更记录

日期：2026-11-08
主题：模型中心接入真实共享仓库扫描＋ComfyUI 镜像拉取／预置流程

## 背景

按 0.0.1.0 遗留事项推进：模型中心从 Demo 模拟接入真实共享仓库目录扫描，让实例挂载的模型在界面可见、可管理；同时落地镜像拉取／预置流程，解决"实例镜像必须本地存在"的使用门槛。

## 后端

### `internal/model/model.go`（新增）

- 扫描宿主机共享模型仓库（容器内 `/data/flowpilot/models`，对应宿主机 `~/.local/share/flowpilot/shared/models`）。
- 第一层子目录映射 ComfyUI 类别约定：checkpoints→Checkpoints、loras→LoRA、vae→VAE、controlnet→ControlNet、embeddings→Embeddings、upscale_models→Upscale Models；未知子目录保留原名，根目录文件归"其他"。
- 跳过隐藏文件／目录与非普通文件；目录不存在时返回空仓库而非报错。
- `Delete(relPath)` 物理删除：路径清洗＋穿越防护（拒绝绝对路径、`..`），只允许删除普通文件。

### `internal/image/image.go`（新增）

- `Puller` 串行管理镜像拉取：同一时刻仅一个任务，重复提交返回 409。
- 拉取在后台 goroutine 执行（与请求生命周期解耦），状态机 idle→pulling→done／error，进度事件实时更新。

### `internal/docker/client.go`

- 新增无超时的 `streamClient`，用于长时间流式响应。
- `PullImage(ctx, image, onEvent)`：POST `/images/create`，逐行解析 JSON 进度流，错误行即失败；镜像名自动拆分 tag（缺省 latest）。

### `internal/server/server.go`

- 新路由：`GET /api/v1/models`、`DELETE /api/v1/models?path=`、`GET /api/v1/images/check?image=`、`POST /api/v1/images/pull`、`GET /api/v1/images/pull`。
- `Version` 提升为 `0.0.2.0`。

### 测试

- model 包 4 用例：类别映射、缺失目录、删除与重复删除、路径穿越；image 包 3 用例：名称校验、拉取生命周期与冲突、失败记录；server 包新增模型接口全生命周期用例。六包 `go test ./...` 全过，gofmt／vet 干净。

## 前端

- `api.ts`：`ModelFile`／`ModelReport`／`ImageCheckResponse`／`ImagePullStatus` 类型与 `getModels`／`deleteModelApi`／`checkImage`／`startImagePull`／`getImagePullStatus`；新增 `formatBytes`。
- `App.tsx`：模型 3 秒轮询真实仓库（接口可用即真实模式）；真实文件映射为界面模型（id=相对路径，来源"共享仓库"）；删除走真实 API；真实模式下"添加模型"提示放入共享目录（URL 下载留待后续版本）。
- `pages/Models.tsx`：真实模式统计卡（文件数、仓库占用＋根目录、实时扫描）；删除确认框真实文案；运行实例保护沿用。
- `components/CreateInstanceDialog.tsx`：镜像输入防抖 500ms 实时检查本地存在性（已在本机／不在本机双色提示）；缺失时可一键"在线拉取镜像"，2 秒轮询进度，完成后自动转为可创建状态；第二步改为展示真实共享仓库模型。
- `verify-demo.mjs`：真实分支新增镜像存在性检查（创建向导）、真实仓库扫描、种子文件界面展示与删除、镜像检查接口、后台拉取全链路（`quay.io/gpustack/runtime:pause`，层已存在秒级完成）；Demo 分支保留。
