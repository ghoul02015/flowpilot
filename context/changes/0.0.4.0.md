# FlowPilot 0.0.4.0 变更记录

日期：2026-11-08
主题：本地导入真实化＋ComfyUI 镜像预置策略＋出图闭环实测

## 目标回顾

周董指令：做本地导入真实化＋正式 ComfyUI 镜像预置策略（基于 Spark 上现成的 `comfyui-h3:spark` 定制默认镜像），让"空机安装→建实例→下模型→出图"的交付演示完全闭环。

## 代码变更

### 后端

- `internal/download/download.go`
  - `Task` 新增 `Kind`（download｜import）与 `Source` 字段；新增 `ImportSpec{Path, Category, Name, SHA256}`。
  - `NewManager(root, importDirs)`：导入白名单目录列表注入。
  - `CreateImport`：源路径必须为白名单目录内的普通文件；名称留空取文件名；复用 `buildTarget` 做类别／文件名／SHA256／仓库冲突校验；`register` 抽出公共登记逻辑（仅进行中任务占用目标路径）。
  - `start()` 按 kind 分发：`runImport` 以 `.part` 分片带进度复制，完成后与下载共用 `finish()` 校验归档；导入同样支持暂停（恢复时从头复制）。
- `internal/server/server.go`：`POST /api/v1/imports` 路由＋handler，错误映射与下载一致；`Version` 提升为 `0.0.4.0`。
- `internal/instance/instance.go`
  - `Spec`／`Defaults`／`Instance` 新增挂载目标字段（`ModelsTarget/OutputsTarget/WorkflowsTarget`），标签 `flowpilot.instance.models-target` 持久化。
  - `NewManager` 追加三个默认挂载目标参数（空则回落 `/data/models|outputs|workflows`）；`targetPattern` 校验目标路径合法性并拒绝 `..`。
- `cmd/flowpilotd/main.go`：注入 `FLOWPILOT_IMPORT_DIRS`（默认 `/data/import`）与三个 `FLOWPILOT_COMFYUI_*_TARGET` 环境变量。
- `internal/docker/client.go`
  - `doWith` 支持指定 HTTP 客户端；`StopContainer` 改用无全局超时的流式通道（请求上限＝优雅停止时长＋15 秒）。
  - 停止请求失败时回查容器真实状态，已退出视为成功——修复大容器停止 502（根因：ComfyUI 不响应 SIGTERM，Docker 等满 10 秒才 SIGKILL，而客户端全局超时也是 10 秒，先于 Docker 返回）。
- 测试：download 新增导入正／反用例；docker 新增停止状态回查用例（已退出→成功、仍运行→报错、304→成功）。

### 脚本

- `install.sh`（VERSION=0.0.4.0）
  - 新建并挂载 `${INSTALL_HOME}/import` → `/data/import:ro`。
  - 默认镜像预置策略：`FLOWPILOT_COMFYUI_IMAGE` 指定 → `comfyui-h3:spark` → `comfyui:latest`，取第一个本地存在的写入容器环境。
  - 挂载目标自适应：读取选中镜像的 `Config.WorkingDir`，非空则注入 `<wd>/models`、`<wd>/output`、`<wd>/user/workflows` 三个 TARGET 环境变量；为空保留 `/data/*` 约定。
  - `environment` 文件记录选中的 `FLOWPILOT_COMFYUI_IMAGE`。
- `demo-docker.sh`：版本提升，Demo 数据目录外新增 `.tmp/flowpilot-import` 挂载。

### 前端

- `api.ts`：`DownloadTask` 增加 `kind`／`source`；新增 `ImportSpec` 与 `createImportApi`。
- `App.tsx`：真实模式"本地导入"改调 `createImportApi`（移除"后续版本接入"提示）；模型列表与任务中心按 kind 展示"本地导入／模型导入"。
- `AddModelDialog.tsx`：真实模式导入说明更新（/data/import 白名单）；导入路径校验对真实模式同样生效。
- `scripts/verify-demo.mjs` 真实分支新增：
  - 本地导入：界面创建 `/data/import/regress-import.safetensors` 导入任务→API 确认 completed＋入库→界面删除。
  - ComfyUI 实例：用默认预置镜像（comfyui-h3:spark）创建 `comfy-real`（GPU 0、18189→8188）→ 轮询 `/system_stats` 出现 comfyui_version（上限 180 秒）→ 停止→删除。
  - 健壮性：种子文件删除改轮询收敛（仓库扫描有秒级缓存窗口）；任务中心重名匹配取第一条。

## 实测记录（DGX Spark，192.168.0.77）

- 安装输出确认策略生效：`ComfyUI 默认镜像：comfyui-h3:spark`＋`挂载目标：/app/ComfyUI/{models,output,user/workflows}`。
- 回归套件 **34 项全部通过**（首轮 33 过 1 失败=停止 502，修复后复跑全绿）。
- 出图闭环：
  1. 平台下载引擎从 hf-mirror 拉取 SD1.5 `v1-5-pruned-emaonly.safetensors`（4.27 GB，约 10 分钟；SD2.1 仓库在镜像站被门控 404，改用 SD1.5）。
  2. API 创建实例 `gen-demo`（comfyui-h3:spark、GPU 0、18190→8188），与生产容器 `comfyui-h3` 共享统一内存（剩余约 77 GB）。
  3. `/system_stats` 返回 comfyui_version 0.44.0 后提交 6 节点工作流（CheckpointLoader→CLIP±→EmptyLatent 512²→KSampler 20 步 euler→VAEDecode→SaveImage），一次成功。
  4. `/view` 取回 `FlowPilot_00001_.png`（512×512，宇航员骑马火星），图像正常。
  5. 清理：停止并删除实例、删除 4.27 GB 模型、删除任务记录；`comfyui-h3`（8188）与 FlowPilot 均健康。
- 过程中发现 Spark SSH 间歇性卡顿（认证后无响应），改走"Mac 临时 HTTP 服务＋Spark curl 拉取"完成发布包传输；不影响产品本身，记为运维备注。
