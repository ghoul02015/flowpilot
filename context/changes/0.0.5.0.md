# FlowPilot 0.0.5.0 变更记录

日期：2026-11-08
主题：任务持久化＋ComfyUI 制图进度＋应用跳转（周董指令：开始做任务持久化；界面只显示 ComfyUI 制图任务进度；首页与实例页提供点击链接跳转实际应用；FlowPilot 定位为环境与部署管理。原机业务容器测试后保持停止。）

## 新增

### 1. 任务持久化（download 包）

- `NewManager(root, importDirs, storePath)` 三参签名；`storePath` 为空则不持久化（单测隔离）。
- 任务快照结构 `persistedTasks{Tasks, IDSeq}` 落盘 JSON；`persist()` 在注册／状态迁移／完成／失败／暂停／取消／删除时原子写入（`.tmp`＋rename，0600）；进度推进不触发落盘（恢复进度靠 `.part` 分片文件偏移）。
- `load()` 启动恢复：completed/failed/cancelled 原样恢复；running/paused 统一恢复为 paused，文案按 kind 区分——下载"平台重启，下载已暂停，可断点续传"，导入"平台重启，导入已暂停，可继续"。
- 任务 ID 序号（idSeq）随文件持久化，重启后新任务 ID 不回退。
- 落盘位置：容器内 `/data/flowpilot/tasks.json` → 宿主机 `~/.local/share/flowpilot/shared/tasks.json`，与模型同卷，重装不丢、卸载随一键清理删除。
- main.go 传入 `filepath.Join(dataDir, "tasks.json")`。

### 2. ComfyUI 制图状态代理（server 包）

- `GET /api/v1/instances/{name}/comfy/status`：运行中实例经 `http://<gateway>:<port>` 请求 `/queue`＋`/system_stats`，返回 `{reachable, instanceStatus, queueRunning, queuePending, comfyuiVersion}`；未运行实例直接返回 `reachable=false`；单次响应限 1MB，整体 4 秒超时。
- `New(...)` 第 8 参 `comfyGateway`（空默认 `host.docker.internal`）；main.go 读 `FLOWPILOT_HOST_GATEWAY` 环境变量。
- install.sh／demo-docker.sh 的 `docker run` 增加 `--add-host host.docker.internal:host-gateway`（Linux 容器访问宿主机映射端口的前提；旧版本容器无此条目，须重装生效）。

### 3. 前端制图进度＋一键跳转

- api.ts：`ComfyStatus` 接口＋`getComfyStatus(name)`（6 秒超时）；types：`Instance.comfy` 可选字段。
- App.tsx：轮询中对运行中实例 `Promise.allSettled` 并行探测，合并进 `comfyStatuses` state（沿用 3 秒轮询节奏）。
- Instances.tsx：表格「模型」列替换为「制图任务」列（`data-testid="comfy-queue-<name>"`）：运行 X · 排队 Y／空闲／服务启动中…／探测中…／—；操作列新增「打开 ComfyUI」按钮（ExternalLink 图标，realMode 且 running 时显示，新窗口打开 `http://<hostname>:<port>`，`aria-label="打开 <name> ComfyUI"`）；详情弹窗「模型数量」替换为制图任务摘要（含 ComfyUI 版本）。
- Dashboard.tsx：实例概览表新增「制图任务」列（同款徽标逻辑）。

## 实机验证记录（DGX Spark 192.168.0.77）

- **持久化链路**：API 创建 120 MB 下载（宿主机限速源 ~1.6 MB/s）→ 40% 时 `docker restart flowpilot-web-demo` → 任务恢复为 paused、文案正确 → `resume` → 完成且 SHA256 校验通过入库；`tasks.json` 在宿主机共享卷确认存在（0600）。
- **续传说明**：源不支持 Range（Python SimpleHTTPRequestHandler 返回 200）时按设计从头重传；Range 源（206）走 `.part` 偏移续传，单测 `TestTasksPersistAcrossRestart` 覆盖。
- **回归 37/37 通过**：新增 3 项——comfy/status 代理 reachable＋版本、实例列表制图任务徽标、打开应用链接新窗口跳转正确端口（18189）。
- 验证产物（persist-test.bin、限速服务）全部清理；`regress-test.safetensors` 种子保留；原机业务容器（comfyui-h3、gpustack、qwen3.8×2）按周董要求保持停止。

## 排障记录（SSH 自动化）

- `pkill -f <pattern>` 的模式会匹配远程 shell 自身命令行（含同样字符串）导致会话自杀——规避：清理与启动拆成独立 SSH 调用，或使用带转义的 pattern（如 `'server\.py'`）。
- ssh 多行命令中的 heredoc 可用，但受其前命令失败影响；写文件改用 base64 更稳。
