# 0.0.7.0 变更记录

- 日期：2026-11-08
- 类型：功能
- 需求来源：周董「优化 ComfyUI 实例模块」（附 DGX Spark 一键部署脚本作为参考）

## 背景与目标

周董提出四个问题并确认模型部分已由模型中心覆盖：

1. 实体机器有现成 Docker 镜像，但新建实例无法选择想部署的镜像版本。
2. 纯净机器需要一键安装脚本，且必须考虑不同显卡。
3. 模型保存路径如何与共享仓库连接。
4. 导出资产文件是否可以手动设置路径参数；安装参数能否通过 UI 向导选择。

评估结论：

- 镜像选择：后端缺「本机镜像列表」接口，前端镜像只能手输——补接口＋三模式选择器。
- 一键安装：吸收 DGX Spark 脚本实战修复（多通道克隆、先装 CUDA 版 torch 防止 PyPI 拉巨型 nvidia 轮子、pip 缓存挂载、国内加速源、PEP 668 规避等），泛化为多显卡自适应；**模型下载明确剔除**——平台职责边界为「脚本只产出可用镜像，模型由模型中心统一分发」。
- 挂载路径：`instance.Spec` 早已支持三个 Target 字段但前端未暴露；本轮向导化并把输出/工作流目标写入容器标签回显。
- 安装参数向导化：脚本生成接口接受查询参数（配方／镜像名／ComfyUI 版本／pip 源／Manager 开关），前端在镜像缺失提示卡内直接下载定制脚本。

## 新增内容

### 后端

- `docker.Client.Images()`：`GET /images/json` 本地镜像摘要列表。
- `image` 包 `catalog.go`：
  - `Recipes()` 六套构建配方（nvidia-cu130/cu128/cu126/cu121、amd-rocm、cpu），含适用计算能力、架构、建议镜像名。
  - `InstallScript(params)`：Go embed 模板渲染一键安装脚本；`InstallParams.Validate()` 白名单校验（镜像名/版本号正则、pip 源枚举、配方 ID 枚举），非法输入回退安全默认，防脚本注入。
- `server` 三个新路由：
  - `GET /api/v1/images/local` — 本机镜像列表
  - `GET /api/v1/images/catalog` — 配方目录
  - `GET /api/v1/images/install-script` — 附件下载定制脚本（variant/image/ref/pip/manager 查询参数）
- 安装脚本模板 `image/assets/install-comfyui-image.sh.tmpl`：
  - 自动检测架构（x86_64/aarch64）与显卡（nvidia-smi 计算能力 → cu130/cu128/cu126/cu121；/dev/kfd 或 rocm-smi → ROCm；否则 CPU）。
  - 安装 Docker（阿里云镜像脚本）、NVIDIA Container Toolkit；配置 Docker Hub 国内加速（幂等合并 daemon.json）。
  - GitHub 多通道克隆（低速 30s<100KB/s 自动切换）ComfyUI（可指定分支/标签）与可选 ComfyUI-Manager。
  - 生成 Dockerfile（AMD 走 rocm/pytorch 基础镜像；NVIDIA/CPU 走 Ubuntu 24.04 + 先装配方 torch 再装 requirements）并 BuildKit 构建。
  - 全程不下载模型；结束页引导到平台新建实例。

### 前端

- `CreateInstanceDialog` 重构第一步：
  - 镜像来源三选一：本机已有镜像（下拉含体积）/ 预置构建配方（含说明）/ 手动输入；本机无镜像时自动切到配方模式。
  - 镜像缺失提示卡：在线拉取 + 「一键安装脚本参数」面板（ComfyUI 版本、pip 源三选、Manager 开关），一键下载定制脚本。
  - 「高级设置」折叠区：模型仓库（只读）/输出（导出资产）/工作流挂载目标 + 容器端口；说明宿主机共享目录位置。
  - 确认页新增挂载映射与导出资产路径行。
- `Instances` 详情页：数据目录硬编码文案改为真实 modelsTarget/outputsTarget（旧实例无标签时回退默认文案）。
- `api.ts`：`getLocalImages`/`getImageCatalog`/`installScriptURL`、`LocalImage`/`ImageRecipe` 类型；`CreateInstanceSpec`/`RealInstance`/`InstanceDefaults` 扩展挂载字段。

### 脚本

- `code/scripts/install-comfyui-image.sh`：默认参数渲染的独立分发版（与平台下载同源模板）。

## 已知问题与风险

- cu128 配方的 aarch64 可用性未实测（PyTorch sbsa 轮子覆盖以官方为准）；脚本按 `uname -m` 设 platform，失败时可改 VARIANT。
- ROCm 配方基于 `rocm/pytorch:rocm6.2_ubuntu22.04_py3.10_pytorch_release_2.3.0`，ComfyUI 新版依赖如要求更高 torch 需后续升级基础镜像标签。
- 脚本内置的 GitHub 加速通道与 Docker Hub 加速源属第三方公共服务，可用性随时间变化，脚本已做多通道容错。

## 回滚说明

`git revert` 本版本提交即可；新增接口与标签均为增量，回滚后旧实例不受影响。
