# FlowPilot 0.0.1.0 变更记录

日期：2026-11-08
主题：实例管理接入真实 Docker API——创建、启停、删除 ComfyUI 容器全生命周期

## 背景

周董要求把实例创建从 Demo 模拟接入真实 Docker API，用真实 GPU 列表创建、启停、删除 ComfyUI 容器。这是 MVP 首个完整落地的功能模块，版本段位由 0.0.0.x 提升为 0.0.1.0。

## 后端

### `internal/docker/client.go`

- 重构出通用 `do()` 方法：支持 POST／DELETE、204 无 body、错误体解析 `{"message"}`。
- 新增 `StatusError`（`Error()` 含状态码文本，兼容既有测试）、`IsNotFound`、`IsConflict`。
- 新增写操作：`ContainerInspect`、`ImageExists`、`CreateContainer`、`StartContainer`（304 视为成功）、`StopContainer`、`RemoveContainer(force)`。

### `internal/instance/instance.go`（新增）

- 实例模型：带 `flowpilot.instance=true` 标签的 Docker 容器，名称、GPU、端口、自启动等配置全部存标签，无数据库。
- 容器命名规则：`flowpilot-comfyui-<name>`。
- 校验：名称正则 `^[a-zA-Z0-9][a-zA-Z0-9_-]{0,31}$`；访问端口 1024–65535；GPU 序号越界拒绝；镜像必须本地存在；名称、端口、GPU 冲突检测。
- GPU 分配：`gpu >= 0` 时 HostConfig 注入 `DeviceRequests`（Driver=nvidia，DeviceIDs=[序号]）；`gpu = -1` 表示仅 CPU。
- 自动挂载共享数据目录 `<hostDataDir>/{models,workflows,outputs}` → 容器内 `/data/{models,workflows,outputs}`。
- `autoStart` 时附加 `RestartPolicy: unless-stopped`；启动失败自动删除容器回滚。
- 抽象 `DockerAPI` 接口便于单元测试；`Defaults()` 返回 image／containerPort／dataDir。

### `internal/server/server.go`

- 新增路由：`GET/POST /api/v1/instances`、`POST /api/v1/instances/{name}/start|stop|restart`、`DELETE /api/v1/instances/{name}?force=1`。
- 列表响应 `{instances, defaults}`；`writeInstanceError` 将校验错误映射 400、未找到映射 404。
- `Version` 提升为 `0.0.1.0`。

### `cmd/flowpilotd/main.go`

- 装配 `instance.Manager`，GPU 数量来自硬件采集器。
- 新环境变量：`FLOWPILOT_HOST_DATA_DIR`（默认回落 `FLOWPILOT_DATA_DIR`）、`FLOWPILOT_COMFYUI_IMAGE`（默认 `comfyui:latest`）、`FLOWPILOT_COMFYUI_CONTAINER_PORT`（默认 8188），新增 `envInt` 辅助。

### 测试

- `instance_test.go` 新增 7 个用例（fakeDocker 桩）：创建成功、名称非法、端口越界、GPU 冲突、镜像缺失、启动失败回滚、删除；`server_test.go` 新增无管理器 503 用例。四包 `go test ./...` 全过，gofmt／vet 干净。

## 前端

- `api.ts`：新增 `RealInstance`、`InstanceDefaults`、`InstanceListResponse`、`CreateInstanceSpec` 类型与 `getInstances`／`createInstanceApi`／`postInstanceAction`／`deleteInstanceApi`。
- `App.tsx`：`realInstances` 非空即真实模式，3 秒轮询实例列表；真实实例映射为界面模型；创建、启停、删除走真实 API 后刷新；Demo 分支完整保留。
- `pages/Instances.tsx`：GPU 列显示真实型号（NVIDIA GB10），`gpu=-1` 显示"不分配/仅 CPU"；详情弹窗显示真实容器名与共享目录说明；"打开 ComfyUI"按钮直达 `http://<主机>:<端口>`。
- `components/CreateInstanceDialog.tsx`：真实模式下提供容器镜像、访问端口、容器端口输入与真实 GPU 下拉（含"不分配 GPU（仅 CPU）"）；名称 Docker 兼容校验；提交中状态与失败保持弹窗。
- `verify-demo.mjs`：按 `/api/v1/instances` 是否可用自动分流；真实分支全程 UI 操作 `regress-01` 的创建→访问→停止→启动→删除。

## 脚本

- `install.sh`／`demo-docker.sh`：docker run 注入 `-e FLOWPILOT_HOST_DATA_DIR`，指向安装目录下 `shared/`。
- 全部脚本版本号提升为 0.0.1.0。

## 部署验证（DGX Spark 192.168.0.77）

- 发布包 `flowpilot-0.0.1.0-arm64.tar.gz`（约 33 MB）上传并安装成功，健康接口返回 0.0.1.0。
- Spark 上暂无 ComfyUI 镜像，实测以平台自身镜像 `flowpilot-web:0.0.1.0`（容器端口 18080）作为实例镜像验证生命周期链路；后续有正式 ComfyUI 镜像后仅需改镜像名。
- 界面创建 `regress-01`（GPU 0 · NVIDIA GB10 · 端口 18188），18188 健康可访问；停止、启动、删除均成功；测试后 `docker ps -a` 确认 regress-01 已清理。
- 21 项远程回归全部通过；业务容器 `comfyui-h3` 持续运行不受影响。

## 遗留事项

- 真实 ComfyUI 镜像（如 `yanwk/comfyui-boot` 或慧浪自制镜像）尚未预置到 Spark，待 0.0.2.0 模型中心落地时一并处理镜像拉取／预置流程。
- 实例自启动开关在真实模式下暂为只读（重启策略在创建时确定），后续版本补充 `docker update` 修改。
