# 0.1.0.11 变更记录

- 日期：2026-11-16
- 类型：UI 优化（导航窗浅色系）
- 需求来源：周董指令「0.1.0.11 版本优化：调整 UI 色系界面，主页面色系按上一版本（已换 logo），重点调整导航窗色系，主旋律浅色系；logo 在 docs/logo，点击 logo 跳转主页面」。

## 背景与目标

0.1.0.10 接入慧浪品牌（品红 #921C5F）后侧栏为深色品红底，与浅色系主内容区对比过强。本轮在不改动主内容区色系的前提下，将导航窗统一为浅色主题，并接入完整横向 logo。

## 修改内容（仅 `code/frontend/src/layouts/ConsoleLayout.tsx`）

- 侧栏容器：`bg-[oklch(0.20_0.028_340)] text-slate-300` → `bg-white border-r border-slate-200 text-slate-600`。
- 顶部品牌区：移除深色期白色徽标底板与「慧浪智算 / FLOWPILOT」文字组合，改用 `@/assets/logo-hl.png` 横向完整 logo（h-10）；整区包裹 `NavLink → /dashboard`（aria-label「返回主页面」），移动端点击同时收起抽屉；引入改为 `logoFull`，`logo-mark.png` 保留供其他场景。
- 导航项：选中 `bg-brand-50 font-semibold text-brand-700`（图标 brand-600），未选 `text-slate-500 hover:bg-brand-50/60 hover:text-brand-700`；焦点框 outline-brand-600；任务计数徽标 `bg-brand-100 text-brand-700`。
- 底部状态卡：`border-white/8` 深色卡 → `border-slate-200 bg-slate-50/70` 浅色卡，标题 slate-800、副文 slate-500；在线/离线圆点微调为 emerald-500/rose-500。
- 版本 footer：`border-white/8 text-slate-500` → `border-slate-100 text-slate-400`。
- 移动端关闭按钮：`text-slate-300 hover:bg-white/10` → `text-slate-400 hover:bg-slate-100`。
- 主内容区（页面背景、顶栏、各页面）未做任何改动，保持 0.1.0.10 色系。
