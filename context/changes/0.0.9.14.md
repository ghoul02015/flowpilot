# 0.0.9.14 变更记录

- 日期：2026-11-11
- 类型：功能（安装升级与回滚·精简版）
- 需求来源：docs/0.1.0.0版本规划.md 十二

## 范围决策（精简）

签名/SBOM/双架构 CI/ComfyUI 模板包留 0.0.9.16 开源 RC；跨版本回滚用 pre-upgrade 快照（手动）。本版交付升级安全链路。

## 新增内容

- **install.sh 升级保护**：检测已有安装→升级模式（记录旧镜像用于回滚＋SQLite 升级前快照 `backups/pre-upgrade-<时间戳>.db`）。
- **健康门自动回滚**：新版本容器 30 秒未 healthy→自动用旧镜像重启容器并 exit 1（失败日志保留）。

## 测试与验证

- Spark 实机升级验证：「升级模式：保留旧镜像 0.0.9.13」＋快照生成＋旧镜像链完整（0.0.9.11–14）＋新版本 healthy＋comfy-01 无损。
- 健康门回滚路径为脚本逻辑（bash -n 语法校验）；失败注入场景留 0.1.0.0 总验收。

## 已知问题与风险

- 旧镜像依赖本地保留（docker image prune 会清掉）；跨大版本回滚需配合 pre-upgrade 快照手动恢复 DB。
- 升级不停止 ComfyUI 实例（规划原则，实测 comfy-01 连续 9 次升级零中断）。

## 回滚说明

- 自动：健康门失败时 install.sh 自动回滚旧镜像。
- 手动：`docker rm -f flowpilot-web-demo && docker run ... flowpilot-web:<旧版本>`；DB 恢复用 backups/pre-upgrade-*.db 覆盖 shared/flowpilot.db。
