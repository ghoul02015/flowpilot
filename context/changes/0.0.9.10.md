# 0.0.9.10 变更记录

- 日期：2026-11-11
- 类型：功能（镜像中心与可信供应链·精简版）
- 需求来源：docs/0.1.0.0版本规划.md 八

## 范围决策（精简）

完整模板体系（SBOM/签名/provenance/兼容矩阵）留 0.0.9.16 RC；本版交付可信校验核心链路＋引用保护＋独立镜像中心。

## 新增内容

- **镜像可信校验**：`instance.Create` 强制校验镜像 `flowpilot.kind=comfyui` 标签（镜像中心构建的镜像自动携带）；受控环境逃生阀 `FLOWPILOT_IMAGE_ALLOW_UNLABELED=1`（demo 注入，生产默认关闭）。`docker.Client.InspectImageLabels`。
- **镜像删除引用保护**：`DELETE /images/local` 前检查实例引用，被使用镜像返回 409（含实例名与状态）。
- **独立镜像中心**：一级导航新增「镜像中心」（ImageManager 从实例页 tab 移出）；实例页聚焦实例列表。

## 测试与验证

- 后端 14 包全绿（新增 TestUnlabeledImageRejected：无标签拒绝＋逃生阀放行）。
- 前端 lint＋build 全绿；本机 E2E 82 项全部通过。
- **Spark 实机**：无标签镜像（comfyui-h3:spark）创建实例被 400 拒绝（文案明确）；删除被 comfy-01 引用的镜像 409；comfy-01 全程运行不受影响；0.0.9.10 healthy。

## 已知问题与风险

- 逃生阀在 demo 默认开启（回归镜像无标签）；生产安装默认关闭——Spark 现有 comfy-01 重启不受影响（校验仅限创建）。
- SBOM/签名/digest 拉取/模板目录留 0.0.9.16。

## 回滚说明

- 回滚 0.0.9.9 直接部署旧镜像；校验与引用保护为新增行为，旧版无此约束。
