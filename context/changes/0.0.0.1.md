## 2026-11-04 Web Demo 与 Docker 交付补充

### 需求与版本决策

用户要求首个代码构建仍使用 `0.0.0.1`，先完成 Web Demo 并部署到本机 Docker；同时增加每轮代码和版本日志同步 GitHub 的规则。本轮不递增版本号，在同一版本记录中追加交付内容。

### 新增与修改

- 基于 React、TypeScript、Vite、Tailwind CSS、shadcn/ui 和 Lucide 图标构建 Web Demo。
- 完成首页看板、ComfyUI 实例、模型中心、任务中心和系统管理五个页面。
- 实现实例创建、启停、重启、删除、自启切换和 GPU／端口冲突校验的模拟交互。
- 实现模型 URL 下载／本地导入模拟、进度推进、暂停、继续和保护性删除。
- 实现任务筛选、日志、取消和重试，以及环境检测、设置保存和诊断 JSON 导出。
- 使用 `localStorage` 保存 Demo 数据，支持一键重置；未连接真实后端或 ComfyUI。
- 新增多阶段 Docker 构建、Nginx 静态服务、健康检查和 `demo-docker.sh` 管理脚本。
- 修复移动端表格导致页面横向溢出的问题，为通用面板补充 `min-w-0`。
- 修复 Docker 脚本构建新镜像后仍保留旧容器的问题，`up` 现在会重建同名容器。
- 新增 GitHub 同步规则和根目录 `.gitignore`，排除依赖、构建产物、测试截图及敏感文件。

### 主要涉及路径

- `code/frontend/src/`：页面、组件、类型、模拟数据和全局样式。
- `code/frontend/scripts/verify-demo.mjs`：Chrome 端到端验收。
- `code/frontend/README.md`：运行和测试说明。
- `code/deploy/web.Dockerfile`、`code/deploy/nginx.conf`：Demo 运行环境。
- `code/scripts/demo-docker.sh`：镜像及容器管理。
- `PROJECT_RULES.md`：GitHub 同步规则。
- `context/conversations/2026-11-04-002-WebDemo与Docker交付.md`：本轮上下文。
