# 0.0.9.4 变更记录

- 日期：2026-11-10
- 类型：功能（实例运维能力＋硬件可视化）
- 需求来源：用户 0.0.9.4 四项需求（实例日志、模型关联、硬件管理页、首页简述与跳转），方案经审批后实施。

## 背景与目标

0.0.9.3 完成模型中心治理后，运维侧仍缺三块能力：

1. **实例可观测性**：实例启动失败、ComfyUI 依赖安装卡住、长期挂起时看不到容器日志，只能登录宿主机执行 `docker logs`。
2. **模型共享的落地点**：共享仓库已挂载进实例，但实例需要用哪些模型没有「显式关联」概念；希望选中实例关联共享库模型，且**改了不用重启实例**。
3. **硬件透明度**：原首页内嵌的完整硬件面板只服务于首页，无法按物理机看多卡明细，也没有驱动/CUDA 版本；首页反而被大面板挤占。
4. **首页到详情的最短路径**：从首页的机器名/实例名应能一键进入对应管理页并定位。

## 新增内容

### 后端

- **Docker 日志流**（`internal/docker/logstream.go`）：`DemuxReader` 解析 Docker multiplex 8 字节帧头（`[streamType,0,0,0,sizeBE32]`），跨帧拼接、超长行（64KB）截断、半帧缓冲、TTY 容器直通、EOF flush；行首 RFC3339Nano 时间戳拆到独立字段。`Client.ContainerLogs` 走无超时的 `streamClient`，非 2xx 解析 Docker `{"message":...}`。`Client.ContainerTTY` 显式判定是否 TTY（不嗅探字节流）。
- **SSE 日志端点**（`GET /api/v1/instances/{name}/logs?tail=N`）：首帧 `meta`（tail、tty、container），随后 `message` 帧逐行推送，15 秒注释心跳 `: ping`，收尾 `end` 帧带 `reason`（`eof`／`container_gone`／`error`）；tail 默认 200、上限 1000。
- **模型关联**（`internal/instance/links.go`）：`ListModelLinks` / `SetModelLinksFor` 以全量集合语义 diff 出新增与移除，在 `<instance-links>/<name>/<category>/<file>` 建立符号链接，**链接目标是容器内路径 `/data/flowpilot/models/<category>/<file>`**；校验类别白名单正则、拒绝 `..`／绝对路径／NUL、校验共享仓库中文件真实存在、清理空目录；持互斥锁保证并发安全。
- **挂载与配置解耦**：实例创建时无条件生成 `extra_model_paths.yaml`，其中 `flowpilot_linked:` 节点恒存在（base_path 指向 `models-linked`，覆盖 19 个 ComfyUI 类别）；`flowpilot_network:` 节点仅在 NAS 生效时追加。实例额外只读挂载 `<hostDir>/<name> → /data/flowpilot/models-linked`，标签 `flowpilot.instance.model-links=true` 标记具备该能力。
- **级联清理**：删除共享模型时清理所有实例中指向该文件的链接（`model.Manager.cleanupInstanceLinks`）与空目录；删除实例时清理其链接目录。
- **硬件版本信息**：`hardware.Collector` 解析 `nvidia-smi` 头部输出，报告新增 `driverVersion`、`cudaVersion`。
- 版本号 `0.0.9.4`。

### 前端

- **实例日志弹窗**（`components/InstanceLogsDialog.tsx`）：`EventSource` 订阅 SSE，`role="log"` 日志区、stderr 红色区分、自动贴底跟随（上滚超过 40px 暂停，提供「回到底部」）、缓冲上限 2000 行、下载 .log、非运行实例给出「仅历史日志」提示、`end` 原因文案化。
- **模型关联弹窗**（`components/ModelLinksDialog.tsx`）：按类别折叠分组＋搜索＋已选计数，保存后 toast 提示「ComfyUI 页面刷新即可见」与新增/移除数量；旧实例（无挂载点）展示重建说明卡且禁用保存。
- **硬件管理页**（`pages/Hardware.tsx`）：`PageHeader` + 物理机 `Panel`（主机／CPU／内存／存储四项概要与使用率），`<details>` 概要行右侧展示驱动与 CUDA chip，GPU `data-table` 单卡单行（卡号／型号／显存条／利用率／温度／功耗／状态徽章：≥83°C 高温、≥85% 高负载、其余在线），2 秒轮询、纯只读。
- **首页精简与跳转**：`Dashboard` 内联 `HardwareBrief` 简述条（主机名按钮 → 硬件管理、机型/卡数/驱动/CUDA chip、CPU／内存／存储三条进度条），四张指标卡片可点击跳转；实例概览新增「应用」列（实例名 → 实例管理并打开详情，`打开` → ComfyUI 新窗口）。
- **跨页定位**：`App` 路由状态扩展为 `{ page, focus, token }`，`navigate(page, { focus })` 递增 token，实例页以 token 拼 `key` 重挂载并读取 `initialFocus` 作为初始详情与 3 秒行高亮。

## 行为与兼容性影响

- **接口新增**：`GET /api/v1/instances/{name}/logs`（SSE）、`GET|PUT /api/v1/instances/{name}/model-links`；`/api/v1/hardware` 响应新增可选字段 `driverVersion`、`cudaVersion`（旧前端忽略即可）。既有接口无破坏性变更。
- **配置变化**：实例启动参数新增 `models-linked` 只读挂载与恒生成的 `extra_model_paths.yaml`，**仅对新建实例生效**。旧实例的 Docker 挂载在创建时固定，重启不会补加，故 `model-links` 对其返回 `supported=false`，PUT 返回 409 并提示重建；重建使用相同共享目录参数，模型/输出/工作流不丢。
- **符号链接语义**：链接指向容器内绝对路径，在宿主机视角看是断链（`ls` 显示红色），属预期设计；ComfyUI 在容器内解析正常。
- **目录新增**：`<数据目录>/instance-links/<实例名>/`；删除实例或共享模型时自动清理对应层级，空目录一并回收。
- **界面变化**：首页不再渲染完整硬件面板，改为简述条；硬件明细迁移至「硬件管理」导航项（新页面）。

## 已知问题与风险

- 日志跟随采用单个 SSE 长连接：容器输出极快时（例如刷屏构建日志）前端按行 append 并截断到 2000 行，仍会有可见渲染开销；当前用 2000 行上限兜底，后续如遇性能问题可改为虚拟列表。
- 模型关联不支持旧实例的「原地补挂载」，这是 Docker 挂载不可变的硬限制；已用弹窗文案明确告知重建不丢数据。
- 符号链接列表不做实时监控：ComfyUI 侧刷新页面才重新扫描（这本身是可接受的即时性）。
- PUT 采用全量集合语义，并发两人同时编辑会出现「后写覆盖」，单机单管理员场景可接受。
- 硬件页依赖 `nvidia-smi`；无 GPU 机器显示空态而非报错，统一内存架构（如 DGX Spark）显存列展示「共享 X GB」。

## 回滚说明

- 代码回滚到 `0.0.9.3` 即可：新接口不再被调用，新增挂载与 `instance-links` 目录对旧版本无副作用（旧版本不读取）。
- 若需清理残留：删除 `<数据目录>/instance-links`，并对 0.0.9.4 创建的实例执行删除重建（旧版本实例不受影响）。
