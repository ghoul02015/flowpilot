# 2026-11-09-021 实例镜像分类与构建弹窗

## 用户目标

周董要求将版本升级到 `0.0.7.3`，继续优化 ComfyUI 实例模块：

1. 手动构建和拉取镜像改为两个独立弹窗，在弹窗内分别选择构建参数和在线镜像拉取参数。
2. 本机镜像列表分为「ComfyUI 镜像」与「机器其他镜像」，新建实例时不列出非 ComfyUI 镜像。
3. 构建参数继续细化：CPU 架构、GPU 架构/配方、ComfyUI 版本（在线获取版本号并与源同步）、pip 源、Manager 开关，并生成对应一键构建脚本。
4. 点击构建后，在镜像清单列表中查看构建进度百分比；列表提供日志图标查看实时构建日志；镜像显示构建时选择的参数简述。
5. 做好 bug 排查并部署到实体 Spark 机器验证。

## 本轮实现决策

- 镜像分类规则：优先识别 Docker Image Labels `flowpilot.kind=comfyui`，同时兼容镜像 tag 包含 `comfyui` / `comfy-ui` 的历史和第三方镜像。
- 新建实例只读取 ComfyUI 镜像候选，不展示平台管理镜像 `flowpilot-web` 或其他业务镜像。
- 平台内构建出的镜像写入 FlowPilot Labels，记录构建参数和分类信息。
- 构建进度为近似值：Docker Engine 无总进度字段，当前根据日志中的 `Step N/M`、镜像写入和成功打标签事件推断百分比。
- 在线 ComfyUI 版本使用 GitHub tags API，失败时兜底 `master`，不阻塞用户构建。
- 一键构建脚本只构建 ComfyUI 镜像，不安装 FlowPilot、不下载模型。
