# 011 · 本地导入真实化与出图闭环（0.0.4.0）

日期：2026-11-08

## 周董指令

> 做本地导入真实化＋正式 ComfyUI 镜像预置策略（基于 Spark 上现成的 comfyui-h3:spark 定制默认镜像），让"空机安装→建实例→下模型→出图"的交付演示完全闭环。

## 关键决策

- **本地导入走任务化复制而非直接挪文件**：与下载共用任务模型（进度、暂停、SHA256、冲突检测），界面体验一致；源文件只读挂载（`/data/import:ro`），不破坏宿主机原始文件。
- **导入白名单**：只允许 `FLOWPILOT_IMPORT_DIRS`（默认 `/data/import`，即宿主机 `~/.local/share/flowpilot/import`）内的普通文件，防止容器路径穿越读取宿主机敏感文件。
- **镜像预置策略**：`FLOWPILOT_COMFYUI_IMAGE` 显式指定 → `comfyui-h3:spark`（慧浪 GPU 服务器预装）→ `comfyui:latest`，取第一个本地存在的镜像作为实例创建默认值。
- **挂载目标自适应**：读取镜像 WorkingDir，非空挂到 `<wd>/models`、`<wd>/output`、`<wd>/user/workflows`（h3 即 `/app/ComfyUI/*`），新实例启动即可看到平台模型库；不写死 ComfyUI 路径，兼容任意定制镜像。
- **出图验证模型用 SD1.5**：SD2.1 仓库在 hf-mirror 被门控（404），SD1.5 单文件 4.27 GB 可匿名下载；用平台自身下载引擎拉取（dogfooding）。

## 过程中发现并修复的问题

1. **大容器停止 502**（真实回归抓出）：ComfyUI 不响应 SIGTERM，Docker 等满 t=10 秒 SIGKILL，而 Docker 客户端全局超时同为 10 秒，先于 Docker 返回 → 502。修复：停止走无全局超时通道（上限 t＋15 秒）＋失败时回查容器状态（已退出视为成功，幂等）。补了单元测试。
2. **回归套件两处时序脆弱**：仓库扫描秒级缓存导致删除断言偶发失败 → 改轮询收敛；任务中心历史任务重名 → strict mode 取第一条。
3. **Spark SSH 间歇性卡顿**：认证后无响应（logind 类症状，时好时坏），发布包传输改走 Mac 临时 HTTP 服务＋Spark curl 拉取，附 SHA256 校验。SSH 预期脚本加短超时＋循环重试。
