# 2026-11-16 044 — 新建实例镜像信任标注（0.1.0.15）

## 起因

0.1.0.14 部署 Spark 验证时发现：新建实例对话框能把无 `flowpilot.kind=comfyui` 标签的镜像（如 `comfyui-h3:spark`、在线拉取的镜像）列为候选，提交时被 0.0.9.10 引入的供应链可信校验 400 拒绝——「能选不能建」。周董指示排进 0.1.0.15 修复，构建后部署 Spark 验证并推送。

## 决策

方案：候选标注/禁用未认证镜像，错误前置到表单内。后端 `defaults` 透传逃生阀状态（`allowUnlabeledImages`），前端逐候选读 Labels 判定 trusted：未放行→禁用+标注；已放行→可选+标注；全不可选→表单内指引（镜像中心一键构建 / 管理员逃生阀）。
