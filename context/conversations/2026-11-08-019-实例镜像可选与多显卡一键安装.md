# 2026-11-08-019 实例镜像可选与多显卡一键安装

## 用户目标与新增要求

周董要求优化 ComfyUI 实例模块，附 DGX Spark 一键部署实战脚本（v2.0，含踩坑修复）作参考：

1. 新建实例应能选择想要部署的镜像版本（目前只能手输，实体机有现成镜像）。
2. 设想纯净机器的一键安装脚本，必须考虑不同显卡情况。
3. 模型保存路径怎么和共享仓库连接。
4. 导出资产文件能否手动设置路径参数。
5. 安装参数能否通过 UI 向导选择。
6. 模型部分不用考虑——已有模型中心。

## 已确认的产品和技术决策

- 职责边界：安装脚本只产出可用 ComfyUI 镜像，**不下载任何模型**；模型分发统一走模型中心。
- 镜像选择三模式：本机已有镜像（新接口 `/api/v1/images/local`）／预置构建配方（六套，按显卡分）／手动输入。
- 六套配方：nvidia-cu130（GB10 sm_121，DGX Spark 实战配方）、cu128（sm_100/120）、cu126（sm_80–90）、cu121（旧卡）、amd-rocm6.2、cpu；脚本运行时按 nvidia-smi 计算能力自动选择，VARIANT 可覆盖。
- 脚本生成走服务端模板渲染（Go embed），参数白名单校验防注入；前端在镜像缺失卡内提供参数面板（ComfyUI 版本／pip 源／Manager 开关）与下载按钮；独立分发版落 `code/scripts/install-comfyui-image.sh`。
- 挂载路径向导化：高级设置暴露 models（只读）/outputs（导出资产）/workflows 三个容器内挂载目标；主机侧固定共享数据目录；outputs/workflows 目标写入容器标签并在详情回显，旧实例兼容回退。
- 吸收 DGX 脚本经验：GitHub 多通道克隆低速掐断、先装 CUDA 版 torch 再装 requirements、pip 缓存挂载、Docker Hub 国内加速幂等合并、NVIDIA Container Toolkit 兜底。
