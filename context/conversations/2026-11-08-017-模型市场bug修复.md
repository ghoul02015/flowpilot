# 017 — 模型市场 bug 修复（全词搜索＋弹窗溢出）· 0.0.6.2

日期：2026-11-08 19:06 起

## 周董反馈（附三张截图）

1. 搜索全词「Minimax」搜不出来，只搜「Mini」反而出结果。
2. 弹窗有文字超出 UI 界面显示（qwen 搜索结果页标签栏／卡片／筛选器整体超出弹窗右边界）。
3. 要求详细测试、正确修复、更新小版本。

## 排查结论

- **搜索**：直连 ModelScope 与 Spark 后端链路反复测试均正常（大小写不敏感，6/6 稳定命中）；定位为源站风控间歇返回空列表 → 后端空结果自动重试一次＋前端空结果引导文案优化。
- **弹窗溢出**：复现脚本实测弹窗 672px 被撑出 821px 内容；根因是 DialogContent 的 grid 布局子项 `min-width:auto` 被长文件名（truncate nowrap）撑宽。修复 `[&>*]:min-w-0`（全局弹窗生效）＋市场面板根 `min-w-0`，复测溢出归零。

## 验证

- Go 九包、前端 lint/build 全绿。
