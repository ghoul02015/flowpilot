# 原生物理机部署与公开发布 0.1.0.16

- 日期：2026-11-17
- 版本：0.1.0.16
- 状态：实现、文档与双架构验收已完成；公开发布进行中

## 用户目标

根据当前版本提供轻量化物理机一键部署方案。管理平台不使用 Docker 启动，向导覆盖 NVIDIA 驱动、运行环境、网络、端口、账号密码、后台安装、终端中断恢复和完整日志；同一脚本支持安全卸载。考虑国内外 GitHub 与依赖镜像，并在验证后公开正式仓库、选择开源协议、提供中英双语产品说明和安装使用手册。

## 已确认决策

- 仅管理平台脱离 Docker，由 systemd 原生运行；ComfyUI 实例仍由 Docker 管理。
- 系统级目录：`/opt/flowpilot`、`/var/lib/flowpilot`、`/var/log/flowpilot`。
- 默认端口 `18080`，账号 `admin`；交互安装隐藏输入并二次确认密码。
- 完成检查后公开 `ghoul02015/flowpilot`，沿用 Apache-2.0，发布 `v0.1.0.16`。
- 用户已授权本轮 Git 提交、推送、公开仓库和创建 Release。

## 本轮成果

- 新增统一安装器 `code/scripts/flowpilot-native.sh`，支持 `install`、`resume`、`status`、`uninstall`。
- 支持 `auto`、`cn`、`global` 网络策略，GitHub 官方与多镜像回退、自定义镜像和代理、SHA256 校验、`.part` 续传。
- 支持后台安装、worker PID、flock、防中断续装、完整安装与服务日志、随机密码或 `0600` 密码文件。
- 默认卸载保留业务数据；`--purge` 永久清理；`--remove-instances` 仅处理带产品标签的 ComfyUI 容器。
- 新增双架构打包器和真实集成测试；目标机无需 Go、Node.js、Python。
- 新增中文与英文产品说明、安装使用手册，README 改为原生部署优先。
- 活跃文件版本同步为 0.1.0.16；前端锁文件非破坏性安全修复后审计为 0 漏洞。

## 实际验证与发现

- 后端格式、静态检查和测试全绿；前端 Lint、构建、12 项单元测试通过；三个新增 Shell 脚本通过语法检查与 ShellCheck。
- Gitleaks 扫描 72 个历史提交；仅 SMB `$HOME/.smbcredentials` 路径误报，精确 allowlist 后无敏感信息命中。
- 首次 Ubuntu 集成测试发现 `/etc/os-release` 的 `VERSION` 覆盖产品版本，已修复并重建。
- 后续测试发现后台 worker 未继承离线来源，已修复续装配置。
- arm64 测试发现前台转后台时重复获取 flock 导致 worker 退出，已改为继承同一锁描述符；继续测试发现完成标记早于锁释放，已调整为先释放锁再写完成状态。
- 幂等 `resume` 随后发现全局命令软链接指向安装器目标时发生同文件复制错误，已加入 `-ef` 同文件判断。
- 最终候选包的 arm64 与 amd64 七阶段全生命周期测试均通过，退出码均为 0；覆盖故障注入、后台断点续装、真实健康与登录、密码日志检查、幂等复装、保留数据卸载、离线后台重装和 purge。
- arm64 保留底镜像预置的 `flowpilot` 用户，amd64 删除安装器新建的用户；此前“预置用户未删除”的断言误判已纠正。
- 尚未在真实 DGX Spark、真实 systemd PID 1 或 NVIDIA GPU 上验证本版本；隔离测试使用 systemctl／Docker CLI shim，flowpilotd、SQLite、健康接口和认证为真实运行。
