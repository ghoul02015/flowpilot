## 弹窗问题结论

实际浏览器复现到弹窗计算背景为 `rgba(0, 0, 0, 0)`。根因是全局 CSS 将 shadcn 主题变量写为完整 OKLCH 颜色，而 Tailwind 配置通过 `hsl(var(--background))` 使用，导致 `bg-background` 无效。

已统一改为 HSL 通道变量，直接引用处增加 `hsl(var(...))`，并同步修复 Sonner。回归测试等待弹窗动画结束后断言背景非透明且透明度为 1，截图已人工查看确认正常。

## 0.0.0.2 已确认技术决策

- 后端使用 Go 标准库，优先保持轻量，不引入重型框架或 Docker SDK。
- 本机没有 Go 命令，使用 `golang:1.25-alpine` 容器格式化、测试和编译。
- Docker 通过 Unix Socket 访问，首版只读 Engine 和容器信息，不开放真实容器写操作。
- Go 同时服务 React SPA 和 `/api/v1/`，一体化运行镜像不再使用 Nginx。
- 前端实例、模型、任务继续使用浏览器 `localStorage`，系统页先接真实后端与 Docker。
- 页面明确区分真实 Docker 信息和 Demo 硬件／GPU 数据，不声称已实现宿主机 GPU 检测。
- Docker Socket 挂载仅限本机受信演示，认证和权限收敛是生产前置任务。
