# 015 — 模型市场（ModelScope 优先）· 0.0.6.0

日期：2026-11-08 15:58 起

## 周董需求

> 主要优化模型中心这个功能版块，在添加模型中，看看能不能直接显示目前主流的一些模型源，选择模型后就直接开始下载了。看看这个主流的模型名称选择的数据更新，能不能和 modelscope 或者 HF 这些做一些对接，当然优先 modelscope，HF 国内很多访问不了，但是可以做备选。

## 决策与实现要点

1. **源验证**：实机 curl 验证 ModelScope 直链格式（`/models/<org>/<repo>/resolve/master/<file>`）与文件列表 API（`/api/v1/models/<repo>/repo/files?Revision=master`）；HF 备选统一走 hf-mirror.com。14 个主流条目逐条验证真实存在；AI-ModelScope/4x-UltraSharp、Detail-Tweaker-LoRA 在 ModelScope 不存在，未收录。
2. **后端**：新增 catalog 包（内置 14 条＋缓存合并＋在线刷新大小与可达性，原子落盘 shared/catalog.json）；新增 `GET /api/v1/models/catalog` 与 `POST .../catalog/refresh`。
3. **前端**：添加模型对话框改三标签，默认「模型市场」——搜索、类型筛选、条目卡片、选中即下载（复用既有下载引擎，任务持久化自动生效）；已入库自动标注；HF 受限条目标「需授权」。
4. **版本**：新功能按规则次版本位升级 0.0.5.1 → 0.0.6.0。

## 实机验证（DGX Spark · 192.168.0.77:18080）

- 42 项远程回归全部通过（含 49.5MB LoRA 从 ModelScope 真实下载→入库→界面删除）。
- 在线刷新实测：14 条全部 reachable，大小更新为 API 真实值（SD1.5 3.97→4.27GB），缓存落盘。
- 排障两则（均修复并回归验证）：
  - 回归选择器歧义：HF 镜像按钮 aria-label 含主按钮前缀 → exact 匹配。
  - 界面删除时序竞争：列表 3s 轮询滞后 API，误点同名 dl- 任务行触发 409 cancel → 删除前等待任务行消失、仅剩文件行。
- 机器状态：原机业务容器保持停止；回归后实例列表为空、模型仓库已清理、catalog.json 留存（属正常缓存）。
