# 对话上下文 2026-11-07-006：真实硬件采集接口（0.0.0.5）

## 用户目标与新增要求

- 把 DGX Spark 的 nvidia-smi 与统一内存指标接入真实 `/api/v1/hardware` 接口，替换当前 Demo 遥测。
- 以 `192.168.0.77` 这台 Spark 作为现成联调环境。
- 过程中命令审批多次过期中断，用户两次确认"继续"后完成。

## 已确认的产品和技术决策

- 采集方案：纯 Go 标准库；nvidia-smi CSV 解析＋`/proc`＋statfs；不引入 NVML 绑定或第三方库。
- 统一内存判定：nvidia-smi 显存字段 `[N/A]` → `unified`，显存展示回退为系统统一内存。
- 镜像基底：Alpine → Ubuntu 24.04（宿主机 nvidia-smi 为 glibc 2.39 链接，musl 无法执行）；离线包 6.7 MB → 约 33 MB。
- GPU 透传：优先 `--gpus all`（Container Toolkit），缺失时手动挂载 nvidia-smi＋libnvidia-ml＋`/dev/nvidia*`。
- 前端策略：真实采集成功显示"本机实测"（隐藏演示机型选择器）；失败回退 Demo 并标注。
- Spark 实测确认该机装有 NVIDIA Container Toolkit，走 `--gpus all` 路径。
