# 会话记录：0.1.0.3 镜像构建失败排查

## 触发

0.1.0.2 发布后，在 Spark 上用镜像中心的 `nvidia-cu130` 配方构建 `flowpilot/comfyui:cu130-2026-11-11`，连续两次失败，任务中心显示进度停在 28%。

错误信息：

```
The command '/bin/sh -c apt-get update && apt-get install -y --no-install-recommends
  python3 python3-venv python3-dev git curl ca-certificates ffmpeg libgl1 libglib2.0-0 build-essential
  && rm -rf /var/lib/apt/lists/*' returned a non-zero code: 100
```

同时任务详情里“开始时间”“结束时间”都是 `—`。

## 排查过程

1. 拉取 Spark 上失败任务的完整日志，看到真实原因不是包名错误，而是索引同步：

```
Err:18 http://ports.ubuntu.com/ubuntu-ports noble-security/main arm64 Packages
  File has unexpected size (1492535 != 1492539). Mirror sync in progress?
E: Some index files failed to download
```

2. 第一版修复改成 https 华为云源，实测发现基础镜像没有 CA 证书：

```
Certificate verification failed: The certificate is NOT trusted
W: ... No system certificates available. Try installing ca-certificates.
```

3. 关键发现：**所有源都失败时，`apt-get update` 退出码仍是 0**（只打印 `W:` / `Err:`）。原来写的 `apt-get update || 回退官方源` 永远不会触发，构建会继续跑到 install 阶段，然后报“Unable to locate package”，把真实原因掩盖掉。

4. 顺带发现 Ubuntu 24.04 已把 `libglib2.0-0` 改名为 `libglib2.0-0t64`，即使索引正常，硬编码旧包名也会失败。

## 修复

- APT 层：按 http 华为云 → 清华 → 阿里云顺序轮询，全部失败才回退官方源；用日志内容（`Err:`/`E:`/`Failed to fetch`/`Some index files failed`）判定成败；索引不可用时输出最近 30 行日志并 `exit 1`。
- 包名：`libglib2.0-0t64` 与 `libglib2.0-0` 按索引实际存在的包自动选择。
- pip：torch 补 `--timeout 300 --retries 5`，requirements 补 `--timeout 120 --retries 5`。这套重试在后续 triton 下载 ReadTimeout 时确实生效了。
- 任务：镜像构建/拉取任务增加 `StartedAt` / `FinishedAt`，取消、中断、正常结束都会写入。

## 验证

- Spark 上先用同样的 Dockerfile 片段单独验证 APT 层：58 秒装完 `python3-dev`、`ffmpeg`、`libgl1`。
- 用 0.1.0.3 重新触发 cu130 构建，完整链路通过：APT → 固定 commit `989d93d` fetch + HEAD 校验 → Manager 克隆 → torch 安装 → requirements → 打包。
- 产物 `flowpilot/comfyui:cu130-fix-0103`，22.2GB。镜像标签、`/opt/flowpilot/comfyui-source.json`、`git rev-parse HEAD` 三者一致。
- 运行时 `torch 2.14.1+cu130`、`cuda 13.0`；`main.py --quick-test-for-ci --cpu` 退出码 0。

## 结论与遗留

- 失败根因是上游 APT 索引同步窗口 + 基础镜像缺 CA 证书 + apt 退出码语义，三者叠加；不是 ComfyUI 版本固定逻辑的问题。
- 完整构建约 1 小时 30 分，主要耗时在数 GB 的 torch/CUDA/workflow templates 下载，Spark 实测 0.3–3.8 MB/s，属带宽限制。
- 遗留：torch 未锁版本（解析到 2.14.1）；`flowpilot.comfyui.commit_date` 为空（release 接口不返回 commit 时间）；统一任务 ID 存在 `img-img-` 冗余前缀（功能可用）。
