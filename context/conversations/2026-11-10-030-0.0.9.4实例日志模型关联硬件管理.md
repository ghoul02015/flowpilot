## 已确认的产品与技术决策

用户通过选项卡片拍板：

| 议题 | 决策 |
|---|---|
| 模型关联语义 | 全量可见 + 关联快捷层（ComfyUI 仍能看到全部共享模型，关联层用于运维聚焦） |
| 日志形态 | 实时流式推送（SSE） |
| 硬件页定位 | 纯只读状态展示（不提供风扇/功耗调优等写操作） |
| 首页硬件 | 精简为简述条（主机名＋卡数＋三条使用率） |
| 老实例兼容 | 仅提示重建（Docker 挂载创建时固定，重启不生效） |
| 链接失效 | 删除共享模型时级联清理实例链接 |

实施中确定的技术方案：

- **双路径视角**：`SetModelLinks(hostDir, containerDir, modelRoot)` —— bind 源用宿主机路径，`os` 符号链接操作用容器内路径（宿主机 `shared` ↔ 容器内 `/data/flowpilot`）。
- **yaml 解耦**：`extra_model_paths.yaml` 无条件生成，`flowpilot_linked` 恒在，`flowpilot_network` 仅在 NAS 生效时追加。
- **能力标记**：靠容器标签 `flowpilot.instance.model-links=true` 判定实例是否具备关联能力，旧实例 GET 返回 `supported:false`、PUT 返回 409。
- **TTY 判定**：用 `ContainerInspect.Config.Tty` 显式决定是否解复用，不嗅探字节流。
- **前端跨页定位**：沿用自研状态机（不引入 react-router Routes），`App` 路由扩展为 `{page, focus, token}`，实例页以 token 拼 `key` 重挂载读取 `initialFocus`，规避 `react-hooks/set-state-in-effect`／`set-state-in-render` 两条 React Compiler 规则。
- **弹窗状态归零**：日志/模型关联弹窗按实例名做 `key` 重挂载，替代 effect 内重置状态（同样是 lint 规则驱动）。
- **删除死代码**：首页完整硬件面板 `HardwareMonitor` 被硬件管理页取代后删除。
