# 2026-11-09-023 镜像构建/拉取任务化（0.0.8.0）

## 用户目标

- 评测当前版本 bug 与 ComfyUI 实例 UI，先梳理不修改；确认后实施。
- 新增需求：手动构建中的镜像支持停止和删除，避免后台挂起重复内容；深入评估多任务并发与残留清理策略。

## 已确认决策

- 决策 A：多任务并发采用**有界并发+排队**（最多 2 构建 + 1 拉取并行，超出排队，同名镜像互斥）。
- 决策 B：任务记录自动保留最新 20 条 + 手动删除单条；成功入库的记录自动清理。
- 决策 C：不自动清 build cache；构建成功覆盖同名镜像时自动清被替换的悬挂镜像；提供手动「清理构建缓存」按钮 + 缓存占用展示。
- 附加：任务记录持久化，重启后未完成任务标记「已中断」；构建前磁盘水位 <15GB 拒绝。
