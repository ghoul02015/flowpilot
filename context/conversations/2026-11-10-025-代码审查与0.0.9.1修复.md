## 审查范围

## 发现并修复（4 处）

1. **真 bug · 数据竞争**：`runBuild` 无锁写 `task.oldID`，与锁内读并发 → 持锁写入。
2. **交互缺陷**：日志弹窗随成功任务记录自动清理而闪关 → 打开时存快照，记录消失回退快照。
3. **交互缺陷**：实例操作双击可穿透渲染快照的忙碌判断 → 增加 `busyRef` 同步拦截。
4. **边界缺陷**：`suggestPort` fallback `8188 + 实例数` 可能撞已有实例端口 → 扫描范围扩至 65535。

审查中确认非问题（不复议）：`pruneDoneWithImage`/`trimFinished` 的原地过滤写法（写下标 ≤ 读下标，安全）；`load()` 循环体取地址（Go 1.22+ 每轮新变量）；镜像任务 ID 重启后撞号（时间戳单调递增）；restart 先停后查 GPU 冲突（目标实例自己占卡，冲突窗口合理）。
