# 008 · 实例创建接入真实 Docker API（0.0.1.0）

日期：2026-11-08

## 周董需求

> 把实例创建接入真实 Docker API——用真实 GPU 列表创建、启停、删除 ComfyUI 容器

## 决策与方案

- **实例模型**：不加数据库，实例 = 带 `flowpilot.instance=true` 标签的 Docker 容器，名称／GPU／端口／自启动配置全部存容器标签，平台重启后状态天然恢复。
- **容器命名**：`flowpilot-comfyui-<name>`，与平台自身容器 `flowpilot-web-demo`、业务容器（如 `comfyui-h3`）互不干扰；列表只认标签，绝不误删宿主机其他容器。
- **GPU 分配**：通过 Docker `DeviceRequests`（nvidia 驱动 + DeviceIDs）精确分配单卡；支持"不分配 GPU（仅 CPU）"；前端下拉来自真实硬件采集的 GPU 型号列表。
- **数据持久化**：自动挂载宿主机共享目录 `{models,workflows,outputs}`，为后续模型中心共享仓库做准备。
- **安全校验**：名称正则、端口范围与冲突、GPU 越界与冲突、镜像必须本地存在；启动失败自动删除容器回滚。
- **验证方式**：Spark 上暂无 ComfyUI 镜像，用平台自身镜像 `flowpilot-web:0.0.1.0`（容器端口 18080）充当实例镜像，验证完整生命周期链路；镜像名可配置（`FLOWPILOT_COMFYUI_IMAGE`），后续替换无需改代码。

## 交付结果

- 后端：docker 客户端写操作（Create/Start/Stop/Restart/Remove/Inspect/ImageExists）＋ instance 管理包＋ 5 个 REST 路由；四包测试全过。
- 前端：实例页真实模式（3 秒轮询、真实 GPU 型号、镜像/端口/容器端口可配、打开 ComfyUI 直达）；创建弹窗三步向导适配真实模式；Demo 模式完整保留。
- 回归：`verify-demo.mjs` 按接口可用性自动分流真实/Demo 分支；真实分支全程 UI 创建 `regress-01`（GPU 0 · GB10 · 18188）→ 访问 → 停止 → 启动 → 删除。
- Spark 实测：21 项远程回归全部通过；测试容器自动清理；`comfyui-h3` 不受影响。
