## 关键坑（本轮修复）

- server.go Version 常量每版必改（脚本改了它没改导致 E2E 版本报错）。
- workspace bind 源路径双层拼接（hostWorkspacesRoot 已含 instances 又拼 instances/uuid）。
- user 挂载目标在旧布局（/data/workflows）下解析为 /data 会覆盖 basePath——仅 userTarget != basePath 时挂载，但目录仍创建。
- 删除保留档误删 DB 记录（onDelete 无条件调用）→ 语义拆分 (name, purge)；MarkOrphanByName 即时标记不等下次 Sync。
- python str.replace 无 assert 会静默失败（SetOrphanMarker 注册丢失排查半小时）——重要替换必须 assert。
- 旧实例兼容：comfy-01 无 uuid 标签，行为完全不变（迁移明确拒绝并提示重建）。
