# 2026-11-04 产品规划与项目管理上下文

- 当前项目版本：0.0.0.1
- 产品名称：慧浪智算·FlowPilot
- 产品阶段：MVP 立项与技术验证准备

## 1. 用户初始目标

用户计划为慧浪智算 GPU 服务器配套一套 ComfyUI 管理平台：

- 一键部署在 Ubuntu 服务器。
- 检测主机硬件参数。
- 一键部署 ComfyUI 和模型。
- 安装脚本执行后，通过 Web 界面管理。
- 优先使用 Docker，支持新建、启动、停止和删除实例。
- 产品轻量化，后续预装在慧浪智算 GPU 服务器上。

## 2. 已确认决策

1. 产品名称正式选择“慧浪智算·FlowPilot”。
2. MVP 聚焦单机、单管理员、NVIDIA GPU 和 ComfyUI。
3. 后端建议 Go，前端建议 Vue 3＋TypeScript，数据库采用 SQLite。
4. 不引入 Kubernetes，不做复杂集群和多租户。
5. 每个 ComfyUI 实例对应独立 Docker 容器。
6. 模型采用全局共享仓库，模型目录只读挂载到实例。
7. MVP 不自动安装、升级或替换 NVIDIA 驱动。
8. 工作流、输入、输出和实例配置持久化，删除实例默认保护业务数据。
9. 模型不使用“启动／停止”术语，统一为下载、暂停、继续、取消、导入和删除。
10. 首发同时考虑在线安装和离线交付，模型包与主程序包分离。

### 项目管理体系

- 当前版本从 `0.0.0.1` 开始。
- 版本号采用“主版本.阶段版本.功能版本.修订版本”。
- 每完成一轮代码修改，默认第四段加 `1`。
- 每轮修改必须更新 `VERSION`、`README.md`、`CHANGELOG.md`。
- 每轮必须在 `context/changes/<版本号>.md` 留下详细记录。
- 记录必须包含修改内容、涉及文件、影响、真实测试结果和下一步。
- 实质需求与技术决策保存到 `context/conversations/`。

## 5. 默认技术参数

以下为 PRD 建议值，仍需立项确认：

- 管理端口：`18080`。
- ComfyUI 端口：从 `8188` 起分配。
- 程序目录：`/opt/flowpilot`。
- 配置目录：`/etc/flowpilot`。
- 数据根目录：`/data/flowpilot`。
- 系统服务：`flowpilot.service`。
