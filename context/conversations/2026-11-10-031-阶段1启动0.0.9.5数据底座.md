## 关键经验

- 回归镜像实例容器无 /data/flowpilot 挂载，flowpilotd 数据库强初始化会使其崩溃循环——管理进程对可恢复初始化错误必须降级不退出。
- Go nil 切片 JSON 序列化为 null，前端 .length 崩溃——API 响应切片一律初始化为空。
- macOS 沙箱拦截 docker buildx activity 写入与 Chrome 临时文件删除，构建/浏览器操作需免沙箱。
