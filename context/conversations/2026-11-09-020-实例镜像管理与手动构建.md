# 2026-11-09-020 实例镜像管理与手动构建

## 用户目标与新增要求

周董要求继续优化 ComfyUI 实例模块，版本号升级到 `0.0.7.2`：

1. 新增「容器镜像管理」，管理本机已有 Docker 镜像，支持增删改、导入、导出等能力，方便环境管理。
2. 手动构建与拉取从新建实例中拆出为子菜单；手动构建应像容器管理一样独立，可在界面一键构建不同显卡版本的 ComfyUI 镜像，并查看实时构建日志。
3. 新建实例中只能选择已准备好的本机镜像。
4. 按项目规则更新版本、变更记录和说明，并部署到 Spark 实机验证。

## 已确认的产品和技术决策

- 实例页增加三个子菜单：`实例列表`、`容器镜像管理`、`手动构建 / 拉取`。
- `容器镜像管理` 是新建实例的镜像来源：本机镜像列表、改标签、删除、tar 导入、tar 导出。
- `手动构建 / 拉取` 承载环境准备动作：在线拉取镜像、按六套显卡配方构建 ComfyUI 镜像、轮询展示构建日志。
- 新建实例弹窗不再支持预置配方/手动输入/拉取/脚本参数，改为只选择本机已有镜像。
- 后端继续使用 Docker Engine API，不引入第三方 Docker SDK。
- 独立分发的一键安装脚本接口继续保留，供纯净机器离线/手工场景使用。
- 不记录远程机器密码或敏感凭据到上下文和变更记录。
