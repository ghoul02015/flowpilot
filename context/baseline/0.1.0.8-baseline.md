## 二、请求行为

以本地演示容器为对象，登录后停留各页面 30 秒统计 `/api/v1/*` 请求：

| 页面 | 主要周期请求 |
| --- | --- |
| 首页看板 | 摘要 3/30 秒、实例 3/5 秒、模型 60 秒、下载 3/15 秒、硬件 5 秒、健康版本 60 秒 |
| 实例列表 / 实例详情 | 摘要、实例 3/5 秒；详情额外健康 5 秒、事件 15 秒 |
| 模型中心 | 摘要、实例、模型 60 秒、下载 3/15 秒 |
| 任务列表 / 任务详情 | 摘要；列表 2/15 秒，详情 2/15 秒（仅当前任务） |
| 镜像中心 | 镜像列表 2 秒（激活时）、任务列表 2 秒 |
| 硬件管理 | 硬件 2 秒 |
| 系统管理 | 摘要、实例、模型、下载 |

详情页不再复制列表轮询：任务详情只请求 `/api/v1/tasks/:id`，实例详情只请求该实例的健康与事件。

## 三、页面与路由事实

- 改造前：页面由 `App.tsx` 的 `page / focus / token` 状态驱动，刷新后回到首页，无法分享深层地址。
- 改造后：13 条路由可刷新、可前进后退、可分享；`?tab=` 与任务筛选参数进入 URL。
- 深链接刷新曾出现白屏：`base: './'` 使 `assets/*` 解析到 `/system/assets/*`，服务端回退 `index.html` 触发 MIME 错误。已改为 `base: '/'` 并纳入 E2E。
- 375 px 下任务中心曾横向溢出 49 px（筛选输入固定 `w-52`），已改为窄屏全宽，七个页面复测为 0–1 px。
